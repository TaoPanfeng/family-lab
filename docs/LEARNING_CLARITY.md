# 教学内容、公式、显微镜与人物整改

## 用户问题与实际改动

1. 数学原有125个核心节点逐一复查主例、数学表述、用途和条件，新增125个按知识点编写的第二情境、公式与易错提醒。命题改用正方形/长方形条件和反例，集合改用真实元素选择与集合运算；不再拿水果人数图作为两课的同一个主实验。
2. 新增22个聚焦概念的小交互，包括数形运算、坐标、排序、方差、条件概率、极限、连续、函数变换、三角定理等。其余节点提供本节公式与逐步例子；相关的原44类基础工具保留但明确标注、可展开，不冒充125套完整专属实验。
3. 基础加减乘除有对象计数、合并、划去、阵列、平均分与余数；原模型和新例子有各自边界。原例和第二例的公式随选择同步，不能换了故事还留原算式。
4. 分数、幂、根式、矩阵、积分、极限等由本地KaTeX输出原生MathML。例题、正式定义、论证、主要数值标签相应排版；未加载远程字体。不是把TeX代码直接放在网页上。
5. 化学新增六个五阶段过程：加热分解制氧、催化制氧、二氧化碳生成与熄焰、石灰水浑浊与过量后转清、铁置换铜、酸碱中和。支持播放/暂停、速度、任意进度和阶段跳转，显示配平式、汉字反应及条件。收集、倾倒不伪造反应；失电子和得电子为同一反应的分开观察。
6. 生物新增五样本明场显微模拟：洋葱鳞片叶内表皮、水生薄叶、花瓣表皮、花粉、精子。支持4/10/40倍物镜与10倍目镜、反向视野、载物台、粗细调焦、照明与光圈、染色、运动和标尺。高倍禁粗调，切换倍数不会自动虚构完美对焦。没有个人样本采集或诊断。
7. 呼吸使用人体胸廓、分叶肺、支气管和膈肌连续联动，另有肺泡与毛细血管交换近景。红细胞留在血管，气体跨膜；胸腔与肺泡可分开放大。
8. 武术用明确CC0授权的连续人体网格替代旧圆柱/球体主体，接续原创关节手。保留练功服/素模/骨架、镜像与近景。修复镜像蒙皮的错误翻转；外观改进不等于动作已经专业审定。

## 验收
- `tests/learning-models.test.cjs`：125节点和公式解析、MathML结构、独立逐原子核算配平、六条时间线、显微倍率与尺度、人体网格/权重。结构与数值检查不等于学科同行评审。
- `tests/learning-browser.py`：逐页两例与推导、22个概念交互、反例判断、基础计数与余数、六实验阶段/播放、五标本变倍/调焦/移动、呼吸分视角、连续人体所有动作与镜像、窄屏布局。真实浏览器使用 `--file` / `--site`；部署后用 `--base` 与 `--require-webgl`。
- 原有完整模型、DOM、数学、全馆体验、物理/坐卧/天文深度回归和手机触摸测试保留。新显微与化学页面另补可信触摸检查。

实际云端与公开网站结果以对应提交的Actions报告为准。本地内容注入不能代替真实导航和WebGL；未做iOS/Android真机全面认证。

## 限制与取舍
这是核心知识科普，不是穷尽教材。理论的例子与一般证明分开，原23组双路线论证保留。未重绘生物馆所有主题，重点解决呼吸和显微探索。显微样本是可复现的合成图，不是显微照片；分辨率表达是简化光学。化学是教学顺序与示意，不是反应速率、气体浓度或火灾预测。人体是通用网格与粗蒙皮、原创关键帧，不是名家动捕、专家审定拳谱或生物力学模型。
