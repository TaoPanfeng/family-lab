# 教学质量整改（2026-10-26）

## 用户要求与验收原则
数学各知识点的例子必须对题，不能用同一个基础工具冒充不同概念。逐项审查125节点，提供生活引入、至少两个情境、逐步推导、误区和正式公式排版。集合与命题须有不同主实验。程序结构测试不能代替数学内容审查。

化学新增有连续播放、逐阶段定位的可视实验；反应阶段显示配平式、中文物质名称与汉字反应，非反应的气体收集/倾倒阶段不可伪造新反应。模拟不提供儿童危险实物实验处方。

生物提供模拟明场显微镜：样本、物镜、载物台平移、粗/细调焦、照明与标尺。光学放大不等于凭空获得更多分辨率；样本明确是合成教学图，不是诊断或显微照片。呼吸要连接机械通气、肺泡交换、血液运输三个过程，避免把整团空气画进血管。

武术人物要有可辨结构、手型和可读动作，参考素材须核验许可。程序化动作不能冒充名家动捕或专家审定。保留手机触摸整改、原馆功能与学习记录。
