# 手机触摸交互整改

目标：手指在地球/地图/人物上操作时，不误触整页滚动；正文保持可滚动，页面缩放不被全局禁止。

## 改动
- 地理与共享三维：按 pointerId 跟踪多指；单指旋转/平移、双指缩放，第三指不制造非法比例。第二指离开后继续单指，无跳变；取消/丢失捕获不当成点选。
- 共享实验区增加“操作模型 / 滑动页面”切换，默认操作模型。触摸约束只作用于模型画面，正文和控件之外保留正常滚动及浏览器缩放；模型内部另有放大/缩小按钮。
- 二维实验使用相同缩放/拖移交互；放大后可移动观察，缩回时限制位移不让图示跑出画框。
- 地图点选命中半径按屏幕像素计算，手机更容易点中小地点；多个点重叠时选最近点，下方列表仍可准确定位。
- 日月地和坐卧：补齐双指初始化、零距离保护、丢失捕获释放；坐卧的捏合不会误触人体部位选择。
- 历史地图：双指缩放，单指平移；取消操作不弹出地点详情。物理把手与化学器材保持首个指针所有权，第二根手指不会抢走拖拽。
- 手机/窄屏关键按钮至少44 CSS像素高，滑条扩大有效触摸区域并隔离纵向滚动；输入、选择、备注使用16px字。小屏参数改为单列；数学选知识点后定位内容而不是重新回到列表顶端。
- 未对 body/document 使用全局 preventDefault，未关闭 user-scalable，也不改学习记录。

## 验收
`tests/mobile-touch.test.cjs` 验证指针生命周期、双指/三指/重合点、取消与释放、阅读模式、卸载。
`tests/mobile-touch.py` 使用 Chromium 的 CDP Input.dispatchTouchEvent，验证浏览器发出的可信触摸事件、实际 scrollY、相机/模型状态和滑条读数；不是把鼠标拖动当作触摸，也不只检查CSS。
覆盖首页与十馆、独立光学页，320/390/430像素竖屏及844×390横屏；地图、人物、双指后单指、取消后重试、阅读区滚动、滑条、收藏、模式、数学选课、历史地图、物理和化学菜单等有限场景。

初始源码在Chromium内容注入中，地理初始场景的单指拖动未复现整页滚动；但旧地图/共享三维无双指处理，取消点选及原生滑条缺乏专项测试。此次增加模型容器级隔离和局部touchmove保护，避免只依赖单一canvas规则。用户手机的具体浏览器状态不能从模拟器推断。

正式结果以当前提交的Actions和上线后的mobile报告为准。--inject是受限本地的补充，不能替代真实file/HTTP。Chromium触摸模拟不是iPhone Safari或Android真机认证，不声称覆盖所有手势或每个按钮的任意状态。原有测试全部保留。

参考：MDN touch-action、Pointer Events；Playwright Emulation及Touchscreen文档。页面手势归属在触摸开始前设置，避免在pointermove里临时改touch-action。
