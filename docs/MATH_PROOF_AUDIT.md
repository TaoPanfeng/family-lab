## 实现与验收

- `proof-engine.js`统一图示接口；四个`proof-*.js`教学模块更新原证明数据并注册具体画面。`proofs.js`保留原数据基线，页面按固定脚本顺序安装四模块。
- 所有当前公式用本地KaTeX生成MathML。图中几何标签采用SVG文本；正式等式在图下渲染。
- 逐步代数变形可以保持同一几何图，当前等式和理由必须同步变化；不会为通过测试随意移动图形。
- `npm run build`生成离线入口；`npm test`包含全部原有模型回归及新增数学测试。
- 数学测试独立检查10,000组格子乘法位权、拼图面积和不重叠、圆面积夹逼、圆锥曲线距离定义、负a二次函数、概率与极限边界。
- `tests/math-proof-browser.py`遍历全部路线与步骤，核对图文/MathML、可见边界、重播、进度、放大、手机布局和可信触摸。
- 发布工作流保留全部旧馆回归，新增证明测试的真实file、HTTP及公开页面验收。工作流成功后才宣布上线。

## 数学与设备边界

定义、样例、一般推导和极限论证已分别说明。剪拼图使用有限参数的准确示例，一般性由文字的面积守恒或相似关系给出；有限动画本身不代替证明。整数单位立方体计数不直接冒充所有实数边长的证明。实数指数连续扩展、切片体积定理和欧氏几何依赖作为前提写出。

浏览器自动化和可信触摸是Chromium仿真，不代表物理iPhone/Safari、Android真机或Windows双击已逐台测试。
