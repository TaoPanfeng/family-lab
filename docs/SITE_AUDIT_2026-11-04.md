# 全站教学与交互检查清单

日期：2026-11-04。检查基线：f214774c274277037a4df9ce41b65fc7c9f09444。本清单先于功能修改建立；原有自动化通过作为基线，不代替本轮内容与使用体验检查。

## 目标与范围

覆盖16个馆及首页、公共控件。检查准确性、教学完整性、交互反馈、手机与键盘可用性、离线能力、记录备份。查阅官方或原作者参考，把适合的做法转成具体改动；保留现有风格与离线运行，不照搬内容、资产或引入运行时外部依赖。

优先级：P1为错误结果、关键功能失效或记录损坏；P2为影响理解或操作的明显问题；P3为有价值的补充建议。每项必须区分“已验证问题”“建议”“本轮已修复”“待后续”，不得把建议当成已完成。

## 所有模块必须逐项回答

| 编号 | 核验项 | 验收方式 |
| --- | --- | --- |
| G01 | 首次进入能知道先做什么、观察什么 | 从入口进入主例，记录第一步及预期结果；术语有解释 |
| G02 | 主例、第二情境和进阶层是否针对本节 | 对照真实条件与画面，不用相同图冒充不同例子 |
| G03 | 搜索、分类、切题、返回是否清楚 | 检查组合筛选、空结果、清除及键盘焦点 |
| G04 | 所有主控件的操作与反馈 | 点击/拖动后对照状态、数字、标签、图形、提示 |
| G05 | 播放、暂停、时间条、速度和重置 | 相邻帧与端点；暂停后不继续推进；重置恢复声明默认值 |
| G06 | 图文、数字、公式、单位和坐标 | 独立计算关键值；区分符号、方向、模型与实测 |
| G07 | 最小值、最大值、零值、无效状态 | 不出现NaN/Infinity；禁用与错误提示有原因 |
| G08 | 320/390/768像素布局及长内容 | 页面无意外横向溢出；必要图表局部滚动/放大 |
| G09 | 可信触摸与手势退出 | 操作区拖动不误滚整页，阅读区能滚动；保留浏览器缩放 |
| G10 | 键盘、焦点、名称和状态 | Tab/Enter/空格可操作；焦点可见；状态与按钮名称对应 |
| G11 | 动态效果与声音 | 减少动态效果呈现正确终态；声音需明确启用，退出/后台停止 |
| G12 | 收藏、笔记、作品与备份 | 刷新保留；导入不覆盖旧记录；错误文件不破坏当前数据 |
| G13 | 来源、许可、日期和边界 | 来源支持相关事实；原创例子与引用分开；不虚构采集或完整覆盖 |
| G14 | 离线和子路径兼容 | 无运行时CDN；真实file、HTTP、上线地址均验收 |
| G15 | 参考吸收与针对性修复 | 写明参考URL、原做法、适用理由、实际改动与验证 |
| G16 | 独立复核 | 作者自查后由其他负责人复核关键改动；保留未覆盖范围 |
