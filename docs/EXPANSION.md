# 四馆扩展：内容、模型边界与验证

本次在原有日月地、物理、化学、历史、坐卧之外，增加 **生物11题、地理8题、宇宙7题、武术5题，共31个可交互主题**。一个首页、九个独立入口，不建立多版本应用目录。原有五馆的业务文件不改写。

## 能做什么

| 馆 | 内容 | 交互 |
| --- | --- | --- |
| 生物 | 动植物细胞、有丝/减数分裂、孟德尔遗传、呼吸与血液循环、神经、睡眠与咖啡因、生殖发育、生理性别、植物繁殖、光合作用 | 观察细胞器、拖动阶段、亲本组合与随机样本、改变条件、对照结果 |
| 地理 | 大洲大洋、经纬度、中国山湖峡谷、河流、麦哲伦—埃尔卡诺与郑和航线、家燕迁徙、历史港口、5A样本 | 离线三维地球、平面图层、地点检索、地图点击、路线时间轴 |
| 宇宙 | 大气层、圆轨道、八大行星、九级尺度、赤道与黄道、光行时、开普勒规律 | 旋转缩放、调整高度/倾角/质量、距离比例切换、阶段切换 |
| 武术 | 站姿观察、八段锦8个方向性片段、太极3个片段、咏春3种手法片段、直拳的空练轨迹 | 三维人体、正侧背视角、关键帧、慢放/暂停、镜像、关节内夹角与双手轨迹 |

每个新主题都有“先猜—动手—看变化—讲原理—再追问”，并提供儿童/进阶解释、知识来源、模型局限、相关主题、收藏、答题记录、观察笔记导入导出。新馆的笔记与旧馆存储分开，不迁移或覆盖旧学习记录。

## 不把演示说成实测

- 生物图形是机制示意，**不是完整三维解剖库**；呼吸频率、循环、神经刺激不是诊断工具。咖啡因半衰期可调，只显示假设下的衰减，不预测个人睡眠，不指导儿童饮用咖啡。
- 遗传模型使用单基因豌豆案例，随机样本不强行凑理论比例。生理性别不决定能力、性格或价值；人类生殖是中性的生命教育。
- 自花授粉仍是有性生殖；扦插是营养繁殖。光合作用的限速是简化资源模型，不是植物产量预测。
- 地理是**精选资料**：24个山地代表点、10个湖泊、8个峡谷、8条河流概略线、12个历史港口、2024年2月6日公告中的21家5A样本，不是中国所有山河或当前全部5A名录。坐标近似，不用于导航；自然海岸图不表示行政边界。
- 航海线是历史概略重建。郑和图为多次航行范围，不冒充单次逐日轨迹。家燕路线是基于种群研究的方向示意，不冒充原始GPS个体数据。
- 宇宙模型明确区分真比例/压缩比例/放大天体。行星为圆形共面轨道与自定初相，不取代日月地馆的星历。星系/宇宙网是程序化结构，不是假称观测星表。
- 本星系群在室女座星系团附近的更大结构中，**不在室女座星系团内部**；拉尼亚凯亚的定义与尺度具有研究背景；可观测宇宙边界不是整个宇宙的边界。
- 武术是原创关键帧与定长骨骼程序化教学编排，**不是完整流派拳谱或名家动作捕捉**。骨盆投影不等于全身重心；关节夹角不代表发力或内劲。不要追求关节极限、憋气、对人击打；疼痛就停止，实际练习需合格指导。

## 参考与复用

采用 PhET 式可操作变量/反馈、NASA Eyes 式尺度切换、人体可分层理解的设计思想；没有复制这些产品的商业模型或受限素材。

实际复用仅有原仓库已附带的 Three.js r140（MIT）与 Natural Earth 海岸几何（公共领域）。所有新界面、模型、图示和编排为本仓库代码；参考出处逐题显示，外部链接需要网络，实验本身不需要。

## 维护和验收

```text
生物模型与交互检查 → 地理检查 → 宇宙检查 → 武术检查
→ 九馆首页与旧馆回归 → 真实 file:// 与 HTTP 子路径
→ 提交源码及离线成品 → Pages 部署 → 在线入口核验
```

本地受限环境的 `--inject` 只验证内容和交互，不能当作真实文件导航或三维渲染验收。云端浏览器检查不使用这个替代模式，三维场景检查启用 `--require-webgl`。检查报告和截图以本次 Actions 的 `browser-test-results` artifact 为准。**本文说明范围与验收方法，不把未运行或失败的测试写成通过。**

普通使用：克隆后打开根目录 `index.html`。后续 `git pull --ff-only`；不需要 npm 或后端。

维护者：

```bash
npm run build
npm --prefix projects/history ci --ignore-scripts --no-audit --no-fund
npm test
python tests/browser-smoke.py --browser /path/to/chrome
python tests/expansion-browser.py --file --require-webgl --browser /path/to/chrome
python tools/prepare-site.py
python tests/site-smoke.py --browser /path/to/chrome
python tests/expansion-browser.py --site --require-webgl --browser /path/to/chrome
```
