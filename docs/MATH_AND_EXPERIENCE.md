# 全站体验、武术人物与数学馆

## 用户目标
默认交付为原 GitHub Pages 网站可访问的更新，不交付 ZIP 让用户搬运。临时工作分支只用于隔离验证，合并发布验收后删除，最终仅保留 main。

## 串行工作顺序
1. 读取线上版本和源码，建立各馆页面、控件、关键状态的验收清单；检查播放/暂停/重置、参数、导航、数据保存、导入导出、移动布局和错误状态。不能用 HTTP 200 或按钮数量代替真实交互。
2. 武术模型：成人比例、四肢连接、躯干与手型清晰，提供练功服/骨架/素模观察和局部近景；动作的来源与局限明确，不冒充动捕或专家认证。
3. 数学馆：小学、初中、高中、大学公共基础和进阶方向的知识地图；节点有儿童入口、数学语言、分步例题、应用场景、前置知识、可操作实验或明确标注的阅读形式。重点定理区分直观演示、例子验证和一般证明；提供不同证明路线。
4. 重新运行原九馆回归与新增检查，部署后对公开网址做端到端验收，并清理临时分支。

## 内容依据与范围
参考教育部义务教育数学课程标准（2022年版）、普通高中数学课程标准，以及 OpenStax 和 MIT OpenCourseWare 的公开数学课程结构；不复制受限教材正文，不冒称与所有地区教材逐页对应，也不把大学所有专业数学分支称为已穷尽。
学习设计参考 Mathigon、The Math Learning Center、GeoGebra：把图、数值和操作相互关联，而非堆文本或只播放装饰动画。应用示例为原创教学情境，不能冒充工程预测或实际仪器测量。
