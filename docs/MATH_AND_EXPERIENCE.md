# 数学馆与全站体验验收

## 交付目标
同一个 GitHub Pages 首页，保留原九馆并新增数学。默认交付网站，不让使用者搬运ZIP；工作分支仅用于隔离验证，合并、发布并核验后删除，最终只保留main。

## 已实现的内容范围
- **125个核心知识节点**：小学1–2年级15、小学3–6年级20、初中22、高中24、大学基础与进阶44。每个节点有儿童解释、数学语言、3步例题、身边用途、工作用途与前置知识链接。
- **44个可复用定量实验**：数与四则运算、平均分、分数等值、数位、单位、钟表、约数、比例、面积体积、勾股、方程、函数、三角与向量、集合、计数与概率、贝叶斯、回归、矩阵、导数、优化、黎曼和、泰勒、微分方程、正态密度、梯度下降、图论、二进制与傅里叶有限和。
- 相关知识可共用实验，**不把125节点说成125套完整独立实验课程**。实分析与拓扑两个节点明确为阅读形式。大学是公共基础及代表性进阶方向，并非所有专业数学的穷尽名录。
- **23个重点结果，各两条论证路线**，关联31个知识点。说明假设，区分面积直观、数值验证和一般推理。某些路线采用同一原理的不同表达，不夸称全部是互不依赖的新证明。
- 搜索、学习阶段与分支筛选、知识地图、前后导航、分步例题、证明路线、儿童/进阶、收藏、手动练习标记、观察笔记、安全导入导出、图示缩放。练过标记不是自动掌握度测评。
- 武术人物增加练功服/素模/骨架模式、关节连接与面部细节，保留手指、掌背与局部视角。仍为程序化教学模型，**不等于完整拳谱、专业动捕、医学人体或内劲/力量测量**。
- 共享二维观察区的放大/缩小/复位改为实际视口变换，并支持放大后拖移和键盘操作；跳到正文不再错误切换科学主题。

## 发现与修复
1. 二维缩放控件此前仅提示而无实际效果：实现真实缩放、平移、边界和复位。
2. 页面跳转锚点被当作课程ID：只处理实际课程的hash，跳转正文保留当前课。
3. 矩阵/向量/复数等几何图横纵比例不一致：采用等尺度坐标，避免正方形被画成矩形。
4. 大尺寸勾股和体积图会超出画布：按所有几何顶点自适应缩放，读数不受显示缩放影响。
5. 数学分子、交集、选择数、矩形边长随其他参数变化时：钳制到合法区间，同步更新控件边界，禁止NaN。
6. 初始程序样例的七五折文字与二分查找比较次数已核对并修正；数学说明为项目原创，不靠填充文字满足长度指标。

## 参考，不复制受限内容
课程组织参考教育部义务教育数学课程标准（2022年版）、高中课程标准公开通知、MIT18.06与公开数学课程目录；大学微积分结构参考OpenStax三卷课程简介。不声称与某一地区教材逐页一致。交互设计借鉴Mathigon/Polypad、Math Learning Center、GeoGebra的可操作变量、直观图形与数值联动思想；没有嵌入其受限代码、图片或教材正文。

入口内逐项提供参考链接，外部阅读需要网络，实验本身无运行时外部资源。

## 验收范围与方法
- `tests/math-models.test.cjs`：知识节点完整性、前置依赖无环、证明结构、44模型边界、独立已知数值与数学不变量；不以结构校验冒充学术同行评审。
- `tests/math-browser.py`：逐一点击125知识页、全部例题步骤、两条证明路线、44模型的每个参数端点、交互预设、图形差异、搜索筛选、记录导入导出、320/390/768/1280/1440宽度与真实来源持久化。
- `tests/experience-browser.py`：五个共享壳应用逐课检查导航、帧进退、播放暂停重置、纠错反馈、模式、放大布局；2D视口像素差异；人物三种显示与四种观察范围；记录每页实际控件清单。
- 原有模型、DOM和浏览器测试全部保留。额外运行原物理深度浏览器测试、坐卧全姿势与步骤检查、日月地深入交互与故障注入；记录实际加载模式。
- 云端执行真实file://、HTTP子路径与WebGL；上线后在公开网址运行数学和关键质量检查。注入HTML只供本地受限环境检查，不算上述三项通过。

**实际结果以对应提交的GitHub Actions日志和`.qa`报告为准。** 本地测试不能预填云端通过，HTTP200不能代替可用性，所有按钮的有限状态巡检也不等于穷尽全部参数组合。Windows、iOS/Android真机、打印设备与专业拳法内容审定不在本次自动化范围内。
