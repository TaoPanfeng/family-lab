## 参考与吸收

1. [W3C 2.5.7 拖动操作](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements)：提供单击/点按替代；方向键可访问仍不足以满足单指针无拖动需求。用于R05。
2. [W3C 2.5.8 最小目标](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)：AA的24×24 CSS像素或规定例外；本项目触摸按钮主动采用44像素作为易用性目标，不称其为AA硬要求。
3. [W3C 状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)：数量、成功或错误消息在不夺焦时仍能被感知。用于R02、备份反馈。
4. [PhET 设计原则](https://phet.colorado.edu/en/about)：操作后的即时反馈、多个表征和适量引导。用于保留明确结果和第一步，而非堆放教程弹窗。
5. [Nielsen Norman Group 系统状态可见](https://www.nngroup.com/articles/visibility-system-status/)：通过当前状态帮助用户判断下一步。用于搜索结果/清除/备份成功失败。
