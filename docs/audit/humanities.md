# 人文四馆检查与修复记录

日期：2026-11-04。范围：历史、语文（字卡及成语/歇后语）、心理学、人情世故。

## 修改前的详细清单

1. 时间、出处、读音：历史公元前后无零年、在位估算与争议；字卡常用读音、字源和原创联想；成语故事年代与现代说法的形成年代。
2. 教学路径：首次阅读提示、针对当前词条的例子、第二情境/对照、误区、可执行的下一步。
3. 目录操作：搜索与类别/收藏/未读组合、空结果、清除、上一项/下一项、换题范围和焦点。
4. 练习：答案默认隐藏、切题清除选择/解析/临时练说；答题之后还能顺畅使用键盘。
5. 动画与声音：字形拆合、逐笔/暂停/复位、描写退出；历史切片播放；声音仅显式点击。
6. 记录：收藏/笔记刷新保留；导入先校验、只合并不覆盖；失败时清楚说明；不保存心理症状/社交选择/私人练说。
7. 小屏与离线：源码无新CDN、相对路径；320/390/768布局、可信触摸、file/HTTP/live由集成人实际浏览器复核。
8. 参考与独立复核：阅读官方/原作者网页，记录吸收点；作者测试后交叉审阅，不把结构检查称为专业史学/心理学全面审校。
