## 实施结果与补充证据

1. **L01 已修复（P2）**：坐卧使用独立半步相位累计；播放恢复先建立帧时基，不把墙钟当进度。修改步频只改变后续速度，同一姿势改参保留当前相位；换姿势归零。切到后台停止步态，并恢复按钮名称。没有新增固定训练步频或必须保持时长。
2. **L02 已修复（P2）**：显微重置/切样本清零时间，恢复低倍和居中；读取减少动态偏好，默认静止，用户仍可主动启用。系统偏好切到减少动态时停止示意运动。后台不绘制；`visibilitychange` 清空帧时基，适用于后台完全不回调 rAF 的真实浏览器情境。
3. **L03 已修复（P2）**：按标本与倍率给下一步。洋葱等低倍先找细胞壁，高倍再比较核；精子不被提示寻找不存在的细胞壁；花粉从未实现染色反应，因此禁用染色并直接说明。焦差、倍率、40×锁粗调与原有教学校准保留。画布新增可见键盘焦点。
4. **L04 已修复（P2）**：既有16种动作分别补齐与原关键帧数量一致的短名称和观察提示，进度中显示从哪一步到哪一步。云手明确为循环，不把循环起点冒充预备式；开弓未还原八字掌/拉弓爪、提踵未独立转脚跟均明确写出。简化手指、模型角度与内劲不可测边界保持准确。
5. **L05 已修复（P2）**：单举分掌左右手在两个上托/下按关键帧保持相反掌向，使用角度插值防止相反法向线性插值变成零向量。继续核对实际几何后发现：原渲染把掌面投影到前臂的垂直面，导致“掌心向下”实际几乎朝前。现以声明掌面为约束，允许示意手腕弯曲；推掌另约束指尖向上。真实 THREE 手组的法向与连续四元数均有回归，测试不只读取文字标签。镜像提示说明侧别沿用原人物标记。
6. **L06 补充检查后已修复（P2）**：显微停止运动或固定染色时，旧 `motion = moving ? time * 8 : 0` 会使精子位置跳回原格。现只冻结时间、不重置平移；去掉周期性平移取模，按稳定的标本格点范围绘制。回归直接记录 Canvas 平移坐标，验证停播/固定染色前后位置一致。
7. **来源补充**：咖啡因课的宽泛 NIH 主题链接更新为已查阅的 NHLBI 健康睡眠习惯页，明确其用于解释持续影响，不把模型剩余量换算成个人入睡时间。

## 集成补查 L07：读取失败后的原始记录保护（P1，修复前证据）

根代理集成发现：坐卧 `load()` 捕获坏 JSON / 未知版本时只设置 `storageOK=false`，但之后的改参、收藏、方案保存仍调用 `persist()`，其成功写回会把 `storageOK` 设回 true，覆盖尚未读取的原始 key，与页面“原始存储没有被自动覆盖”的提示冲突。计划增加独立且本次页面不可自动解除的读取失败锁；保留原 key，允许内存中继续操作、导入与导出当前方案，并以真实 DOM 事件故障注入验证。正常版本和原备份格式不迁移。

L07实施与验证：**已修复**。新增独立 `readFailure` 标志；读取失败后本次页面不会因后续写入成功而解除保护，`persist()` 直接返回 false。把“无记录”严格限定为 `getItem() === null`，使空字符串也进入坏 JSON 保护。警告明确原始记录保留、当前改动仅在本次页面暂存，并指向现有 JSON 导出入口。当前会话仍能合并导入、保存内存方案与导出；未迁移正常存储 key、版本或备份格式。

新增真实JSDOM回归：坏JSON、未知版本、非法方案字段、空记录、读取异常共5类故障，逐一通过实际DOM事件操作身高、收藏、方案保存、导出、导入和页面退出；每类均验证原始字符串逐字不变、写调用0次、警告不隐藏、内存方案可导出且不宣称浏览器保存成功。正常版本另验证沿用原key、旧方案保留、参数/收藏写回与原备份格式可解析。以上属于真实DOM状态和事件回归，不等于真实浏览器布局、触摸或文件协议验收。

定向验证：`node --test projects/posture/tests/core.test.cjs projects/posture/tests/audit-motion.test.cjs` **45/45通过**，语法及diff空白检查通过。新增存储回归6项，坐卧audit共8项。
