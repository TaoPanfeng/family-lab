## 对照参考

1. W3C WCAG 2.2 Focus Order：https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html 。吸收“动态操作后焦点顺序仍保有意义”，用于D01。格子修改应继续留在原格，选词完成应通向检查，适合本馆连续试错。
2. British Council，Present simple – verb to be：https://learnenglishkids.britishcouncil.org/grammar-vocabulary/grammar-practice/present-simple-verb-be 。吸收主体与am/is/are的对应和“说明规则后练习”，用于D02的结构反馈。只保留原创情境与插图，不复制其游戏、题库或音频。
3. CS Unplugged，Kidbots：https://www.csunplugged.org/en/topics/kidbots/ 。对照规划—运行—调试，核验机器人转向、重复中途碰墙、单步/暂停/重置；不把动画速度称为性能实测，不复制素材。
4. MDN Web Audio best practices：https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices 。对照显式用户启音、独立音量与停止；沿用音频时钟，不加入外部库、音频文件或CDN。
