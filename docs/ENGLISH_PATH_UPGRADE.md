## 实施与复核

- E01—E10已实施：32课、192个主例/迁移情境、64组对比、64道双阶段选择题；原三个实验与原笔记格式保留。每题四个选项均有情境依据，正确位置分散。
- 两组内容负责人双向全文复核：骨架/指代 ↔ 时间/语气；扩展/连接 ↔ 阅读/表达。修正过充分条件被误改写为必要条件、指代歧义、改写遗漏原意、词语自然度、题干暗示等问题。
- 从表达目的、角色、时间视角及信息关系解释用法，同时区分语言惯例、可选分析和规则边界。`have trouble (in) doing`区分可选in的传统教学分析与无in直接补足；不把所有-ing解释成省略。
- 解释默认折叠；挑战时隐藏原学习引言与任务提示，题干和选项为英文，提交后按需打开逐项解释。主例与迁移场景切换会同时改变英文与角色块。
- 进度独立记录每题通过编号，两题都通过才清关；开放练说只提供自查，保存在本机，不自动评分。当前课通过后标题、总进度与建议课程同步。
- 练说先暂存在内存，显式保存后才持久化；切课保持各课内存草稿，刷新未保存草稿会丢失。坏原文锁写、可以导出原文/本次工作；导入与正常保存不迁移或覆盖旧三实验记录。
