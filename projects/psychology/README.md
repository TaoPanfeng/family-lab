# 心理学 · 看懂思考，也看见自己的盲点

本馆是知识名词入口，不是测评、诊断、咨询或完整专业课程。首批6类60个概念、每条两个原创假设情境。按用户要求先验证并发布心理学，之后才实现人情世故场景训练。

## 怎样组织内容

判断与偏差、注意与记忆、学习与行为、情绪与动机、社会与关系、自我与研究素养。每条按白话→较严谨定义→孩子例子→生活/工作例子→不适用和误解→自我观察→来源展开。所有案例为本站原创的说明性例子，不能用它诊断任何人。读过不代表掌握；不把所有心理现象都称为“效应”。

知识诅咒不是看不起别人；负强化不是惩罚；认同感受不是同意一切；相关不等于因果；延迟满足不是终身成功预测；达克效应不画网络上流传的必然成长曲线。经典研究、词典定义、理论与争议各有标签，不能用单个行为给人下结论。习得性无助另列2016年的理论修正，区分早期行为解释与后来的机制研究。

## 专业资料

逐条来源在 `data.js` 的sources映射中，有机构/作者、资料类型、支持范围、链接、核对日期。来源包括APA Dictionary、OpenStax Psychology 2e、Noba、MIT课程、自我决定理论研究机构与原始研究。研究和综述只支持其研究条件；中文版定义、情境和行动由本站重写，不抄录现代受版权保护的长篇解释，不声称专业机构为本站背书。正文全部随仓库离线提供，只有主动打开参考链接才联网。

## 交互和隐私

手机优先阅读，目录可展开，分类/中英文搜索/收藏/未读组合筛选，空状态可清除；可比较两个概念、调大字号和上一条/下一条。仅收藏与已读写入 `family-lab-psychology.v1`；不保存心理症状、测评分数或个人经历。导入严格验证、合并去重，拒绝未知条目，保存失败明确提示；清空需要确认，不动其他馆数据。

## 验证

`node --test tests/psychology.test.cjs`：数据、来源URL、关键区分、过滤与备份边界。
`python tests/psychology-browser.py --file`、`--site`、`--base <公开网站根地址>`：逐条内容、相关概念、双概念对照、分类/搜索/空状态、收藏/已读、合法/非法备份、存储失败、字号、手机可信触摸和正常滚页。
`--inject`只用于受限环境中的DOM注入检查，不是file://、HTTP或线上验收。测试数量不代表教学准确性获得专业认证；仍需结合内容人工复核。正式发布保留所有旧馆回归。
