# 语文 · 字里有世界

## 认字 → 拆字 → 组词 → 读句 → 自己造句

首批102个精选字、112个常用读音条目按拼音字母、声调排列；多音字分读音放入目录。可搜索汉字、繁体对应字、无调/带调/数字调拼音、部件及词语，按首字母、主题、收藏筛选。默认从用户提出的“睡”开始。

每张卡有：现代字形、部件观察、原创记忆联想、三个相关词语、原创生活例句、易错提醒及查证入口。四张卡（睡、休、森、清）单列核对后的字源线索；其他卡不把拆字联想当作历史结论。例如“睡”的目与眼睛有关，垂有历史表音作用，“眼皮垂下来”是帮助记忆的故事。

19段古代公版诗文节选，38个读音条目关联相应名句；不是每个字都强配名句。按多音字在句中的实际读法关联，例如“春眠不觉晓”的觉只归jué；“睡觉”的jiào单独讲解。诗句采用常见版本（繁转简），不同版本和古义到链接核对。课堂用字读音应结合现行教材，目录不穷尽古音、异读、人名音和全部用法。

## 可操作内容

- 字形图使用随包笔画矢量路径；可拆开/合起偏旁，独体字不硬拆。拆分按本字部首笔画及其余笔画分组，不保证每个现代部件都能单独拖出，不能当古文字动画。
- 真正的逐笔书写动画；播放、暂停/继续、速度、逐笔和复位。笔顺使用指定版本数据，不假称统一覆盖所有地区书写标准。
- “青字家族”比较清/晴/情/请/睛；多音字按词换读音；12道辨字练习给出具体反馈。
- 自己写一句（最多500字），切换字卡保留草稿；收藏和句子存在当前浏览器，可导出/合并导入。不收集身份信息，不用“看过”冒充掌握。导入先校验，不能覆盖已有句子或执行HTML。
- 手机目录可收起，主要按钮有44像素触摸高度，字形区是观察区，允许正常滑页。没有全页锁滚动、没有禁用浏览器缩放。
- 本地中文语音可用时才启用“朗读例句”；没有本地语音时明确提示，非必需功能，不向外部语音服务发送文字。机器多音字朗读不保证总正确，以卡片注音为准。

## 离线、来源与许可

双击 `index.html` 使用。运行不请求第三方网站；源字库与古诗核对链接需要联网。本项目没有上传用户造句或保存个人身份数据的接口。

Hanzi Writer 3.7.3 是MIT库；102字路径来自 Hanzi Writer Data / Make Me a Hanzi，遵守 Arphic Public License。二者许可证在vendor内；来源版本与校验值在vendor/manifest.json。不是把字体文件随项目分发，也不能将所有资产一概称MIT。

字源核对：香港中文大学汉语多功能字库 `https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/`。古诗逐条提供维基文库原文或字库引文入口；例句、记忆故事、讲解和练习是原创教学内容，不复制受限现代教材。

## 验收

`node --test tests/chinese-models.test.cjs` 验证112条内容结构、排序、声调、名句读法、字形和许可校验、备份边界。
`python tests/chinese-browser.py --file` / `--site` / `--base <网站根地址>` 验证实际页面和逐笔动画、多音字、筛选、挑战、记录、手机触摸与窄屏。
`--inject` 仅可作为环境受限的内容检查，绝不代替真实file/HTTP/线上结论。

有限的程序检查不等于全部字源研究、教学同行审定或每款手机的真机认证；覆盖范围与缺少的内容要如实报告。
