## 本轮修复并回归的具体问题

- 学习模式按钮的选择器限制在模式开关内，避免与页面模式属性混淆。
- 原子页面异常元素参数回退到有效初始状态，超出电子层教学范围的元素不绘制错误的圆环模型。
- 稳定核素不再被错误导航到无关放射性核素；周期表 d 区说明避免把全部 d 区元素一概称为过渡金属。
- 实验室与公共引擎使用一致的锰原子量；分离实验限制盐水范围，避免初始条件或收集终点超出展示所假设的完全溶解范围。
