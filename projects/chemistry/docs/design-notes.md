# 万物化学 · 教学与交互设计说明

## 把学习连成一次发现

这个项目以“选材料 → 搭装置 → 先预测 → 做操作 → 看现象 → 解释粒子与数量 → 记下发现”为基本学习路径。让孩子知道自己改了什么，也让成人能追问为什么、怎样计算、模型在哪些条件下成立。

同一个主题可以从不同入口进入。例如小苏打与醋，实验室呈现气泡和装置，计算台呈现限量反应物与生成量，披萨小游戏提供按份数配料的类比，生活展区再联系面点起泡。页面之间使用明确的主题跳转。

## 从儿童烹饪游戏借鉴的交互

设计参考了 Toca Boca 的儿童探索产品，以及 PhET 的原子和反应物模拟。借鉴点是可见的材料架、直接选择、操作后立即反馈、允许试错和重来、用有限目标组织探索。项目中的界面、SVG 仪器和题目是独立编写的，没有复制原产品素材。

化学学习需要额外说明条件和守恒。因此，材料不会因为点了按钮就凭空变成想要的产物：系统会检查器材、接口、容器、数量和操作顺序，结果来自明确记录的模型。当前未收录的组合会说明模型不支持，不能用“无动画”暗示现实中没有反应。

## 双模式怎样分工

| 设计点 | 小小探索家 | 进阶研究员 |
| --- | --- | --- |
| 目标 | 观察一个清楚的问题，描述发生的变化 | 把现象、粒子、方程式与数量关系联系起来 |
| 讲解 | 较短句子、生活类比、分步提示 | 展示摩尔质量、条件、公式和适用范围 |
| 操作 | 大按钮、预测、点选、连接、随时重来 | 同样的操作流程，并开放允许范围内的数量和参数 |
| 反馈 | 先说看见了什么，再解释一个关键点 | 给出产物、剩余量及计算依据 |
| 共同基础 | 两种模式共享同一化学数据与科学规律 | 两种模式共享同一化学数据与科学规律 |

儿童模式是讲解和操作的简化，不意味着把科学条件全部藏起来。容易形成误解的地方仍保留短提示，例如电子圆环不是轨迹、无色不等于没有溶质、气泡不一定是氧气。

## 为什么保留这些教学模型

- **原子与同位素**：分别操作质子、中子和电子，把元素身份、质量数与电荷拆开观察。电子层计数图限制在前 20 个电子，并另有电子云概念图。
- **半衰期**：同时呈现期望曲线和一组固定随机样本。拖回同一时刻仍显示同一次实验，便于比较“规律”和“单个事件”的区别。
- **反应计算**：输入纯物质或纯溶质的数量，明确限量反应物、未反应余量和未收集产物。气体体积写明温压条件。
- **分离与提纯**：用粒子和物料去向解释过滤、蒸馏、结晶和色谱，避免只把仪器名称当作知识点。
- **电离与酸碱**：区分溶解、电离和导电；让稀释后的 pH 趋向中性，同时呈现强弱电解质的差异。
- **白磷与射线**：提供封闭虚拟观察和概念比较，不给出真实危险材料的制备、点燃或获取流程。

## 操作与可访问性取舍

器材可以点选加入；连线既可点两个接口，也可使用下拉选择。器材有移动按钮，重要动作不依赖精细拖动。页面提供文字结果与状态提示，颜色用于辅助区分。布局设置了窄屏断点、可滚动周期表和减少动画偏好适配。

这些措施已在代码和 DOM 流程层面验证。真实浏览器布局、键盘焦点体验、屏幕阅读器和实体触屏还需要按测试报告列出的设备清单验收。

## 后续扩展的原则

每增加一个实验，同时补充实验目录、物质与器材、有效连接、操作条件、计算或定性模型、观察结果、出处和对应测试。定性动画不能冒充通用反应预测器。增加更多核素或更复杂电子结构时，应扩展数据与模型，不靠猜测补足缺项。

目前用静态网页实现，目的是使完整体验可以离线打开、易于复制和长期保存。学习笔记留在当前浏览器并可导出，后续如需家庭账号、跨设备进度或班级管理，可以再添加服务端功能。
