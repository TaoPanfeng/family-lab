# 万物化学 · 亲子探索实验室

把看不见的粒子、看得见的现象和算得清的数量关系连起来。

## 1. 最快打开

**解压后，用浏览器打开根目录的 `chemistry-explorer.html`。**

- 一个 HTML 包含所有核心页面、样式、绘图和数据，断网也可以用。
- 不需要 Java、Node.js、数据库、账号、CDN 或安装第三方组件。
- 也可以打开 `dist/index.html`，请保留 `dist` 内其余文件。
- 手机建议使用在线版；部分手机文件预览器不会执行 JavaScript，需要交给浏览器打开。真实手机的触屏与布局尚未在本轮环境中完成验收，详见测试报告。
- 学习记录保存在当前浏览器；换设备不会自动同步。可在“我的实验记录”导出 Markdown 笔记。

## 2. 两种学习模式

| 模式 | 怎么学 |
| --- | --- |
| 小小探索家 | 大按钮、一步一句引导、先猜再观察、生活类比，适合亲子一起操作。 |
| 进阶研究员 | 展开方程式、摩尔质量、限量反应物、反应条件和模型假设，适合复习巩固。 |

模式改变讲解深度，不改变质量守恒和粒子计数等基本规律。

## 3. 探索地图

1. **互动实验室**：器材与材料架、可移动的 SVG 实验台、接口连接、定量加料、预测、分步操作、动画和结果解释。
2. **元素周期表**：118 种元素，按名称、符号、原子序数和类别查找；每张卡片包含性质、状态和用途。
3. **原子与同位素**：改变质子、中子、电子，理解元素身份、质量数、电荷和电子层；查看精选核素。
4. **反应计算台**：13 个可定量的反应，输入 g 或 mol，计算理论生成量、回收量、剩余反应物及理想气体体积；还有方程式配平练习。
5. **衰变与射线**：半衰期期望曲线、固定样本的随机衰变、α/β⁻/γ/X 的区别及定性屏蔽示意。
6. **分离与提纯**：过滤、盐水蒸馏、蒸发结晶、纸色谱；能改条件、看粒子、核对物料去向。
7. **电离与酸碱**：糖水与盐水、强酸与弱酸、逐级稀释、导电性和酸碱中和。
8. **生活里的化学**：用交互场景观察发酵、面点起泡、腐蚀、洗涤与硬水等现象。
9. **闯关小课堂**：披萨配料小游戏和 18 道带解释、可重试的题目。
10. **实验记录与资料**：保存观察、导出记录、查看科学来源与模型限制。

## 4. 十二项实验怎么操作

实验均发生在虚拟画面中。先选实验，再按台面引导完成准备和操作。

| 实验 | 主要认识 |
| --- | --- |
| 过氧化氢分解制氧 | 催化剂与反应速率，氧气的收集 |
| 高锰酸钾分解制氧 | 受热分解、装置连接和操作顺序 |
| 小苏打与醋 | 气体生成、反应物与产物、限量试剂 |
| 酸碱中和 | 中和关系、过量反应物与酸碱性 |
| 指示剂变色 | 酸、碱、中性的颜色反馈 |
| 二氧化碳与石灰水 | 澄清到浑浊，沉淀现象与条件范围 |
| 铁与硫酸铜 | 置换反应、金属表面的变化 |
| 氯化钙与碳酸钠 | 可溶物混合后生成不溶性沉淀 |
| 过滤砂水 | 滤纸截留不溶性颗粒 |
| 盐水蒸馏 | 汽化、冷凝、冷却水方向和盐的去向 |
| 水的电解 | 电极连接，氢气与氧气的体积比 |
| 白磷封闭虚拟观察 | 氧气参与燃烧、氧化物与核衰变的区别 |

### 基本流程

1. 从器材架点选或拖放器材。
2. 点击两个接口完成连接；手机也可以使用接口选择控件。
3. 选材料、加入指定容器，调整允许的模型投料量。
4. 先选一个预测。预测错了也能继续观察。
5. 按顺序执行检查、搅拌、模型加热或通电等操作。
6. 观察动画，比较结果和预测，记录发现。

错误材料、错误连接、漏放器材、过早操作都给出原因。未收录的混合物显示“当前模型未支持”，不会误称现实中一定不反应。

## 5. 推荐亲子路线

1. **第一次：气泡从哪里来？** 先做小苏打与醋实验，让孩子说出看到的变化，再一起读二氧化碳的解释。
2. **第二次：谁先用完？** 在披萨工坊把饼底调成 3、芝士调成 4，猜最多做几份，再打开反应计算台。
3. **第三次：世界的积木。** 在原子搭建台分别改变一颗质子、中子、电子，观察三种不同的结果。
4. **第四次：盐去哪里了？** 对比过滤和蒸馏，把“看不见”和“不存在”分清楚。
5. **进阶复习。** 再看酸碱稀释、反应计量和半衰期，先估算再用模型验证。

每次抓住一个问题，鼓励孩子用“我改了……我看见……我猜因为……”说明自己的发现。

## 6. 几条不能省略的科学边界

1. 电子圆环是教学模型，不是电子真实、确定的运动轨迹。原子结构图没有按真实尺寸比例绘制。
2. 同位素的质量数是整数 A=Z+N；周期表中的相对原子质量通常反映同位素组成，二者不同。
3. 反应计量输入的是纯物质或纯溶质数量，不是溶液总质量。默认假设指定反应完全进行、没有副反应。
4. “假设回收率”只改变收集到的产物量；未收集产物仍属于反应产物，不能从质量账本中删掉。
5. 气体体积按干气体、理想气体模型估算，明确指定温度和压强，忽略气体溶解和水蒸气。
6. pH 模型按 25 ℃稀水溶液处理，并计入水自电离；导电性是定性展示，不能直接换算仪表读数。
7. 半衰期公式描述统计期望，不能确定单颗原子核的衰变时刻；射线屏蔽图不能用于现实防护设计。
8. 白磷只提供封闭概念场景；放射性只展示粒子与数学模型，不提供真实材料或操作方案。

完整出处及数据版本见 `docs/science-sources.md`，应用内“资料与模型”也提供原始链接。

## 7. 开发与测试

网页本身无依赖。运行测试报告需要 Node.js 22.17 或以上，不需要 npm install。

```bash
npm test
```

或者：

```bash
node tests/run-report.cjs
```

重新生成单文件版本：

```bash
node build-offline.cjs
```

测试包含化学引擎、实验状态机、探索计算函数以及真实应用脚本的 DOM 事件联调。DOM 测试使用已附带、固定版本的 LinkeDOM，仅用于测试，不是浏览器渲染引擎。

**真实浏览器截图、CSS 实际布局、iOS/Android 触屏手势、浏览器下载对话框尚未验收。** 当前运行环境的受管理预览服务无法启动。这项限制没有被计入“测试通过”。详细结果见 `docs/test-report.md`、`docs/test-summary.json` 和 `docs/test-results.tap`。

## 8. 文件结构

| 文件 | 用途 |
| --- | --- |
| `chemistry-explorer.html` | 直接打开的单文件离线版 |
| `dist/index.html` | 可部署到任意静态服务器的入口 |
| `dist/data.js` | 元素、核素、反应和科学资料数据 |
| `dist/core.js` | 化学式解析、化学计量、核变化和溶液计算 |
| `dist/lab.js` / `lab.css` | 实验台、仪器、连线、材料与实验流程 |
| `dist/explore.js` / `explore.css` | 周期表、原子、衰变、分离、酸碱和生活场景 |
| `dist/app.js` / `styles.css` | 导航、双模式、首页、计算台、小游戏和笔记 |
| `tests` | 自动化测试及仅用于测试的 DOM 依赖 |
| `docs` | 来源、测试结果与设计说明 |

## 9. 部署

把 `dist` 中的文件整体复制到 Nginx、Apache、对象存储静态网站或其他静态托管服务即可。无需 API 服务，路由使用 URL 的 `#`，不需要额外的服务端路由重写。

不要把测试目录、开发文档或本机笔记文件作为网站运行依赖。不要随意把用户输入的材料名称接入真实化学预测结论；扩展新实验时，应同时补充数据出处、流程校验和测试。
