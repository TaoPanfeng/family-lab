# 人情世故 · 真诚表达，彼此有界

## 交付顺序与目的

心理学馆先完成发布及公开网站验收（运行41368285156，2026-11-02）。确认后才开始本馆。不是让使用者反复续传代码，也不把仓库提交当作已部署。

本馆8类48个原创假设场景，覆盖伴侣与家人、亲子与学校、职场协作、朋友与人情、长辈与饭局、日常与公共、线上与文字、道歉支持与边界。每类6题，其中14题可亲子共读。不是完整社交课程、心理诊断或情商测评。

每题：具体场合→对方的话→本次目标→ABCD选择或直接学习→参考选择与四项分析→简短/完整/后续表达→三项实际行动→不能照搬的边界。答案初始隐藏，选项本身不揭晓结果；点击查看才展开，换题、刷新或切换模式后重新隐藏。参考选择是给定情境下较合适的起点，不是唯一的人生答案。

## 内容与资料

定义和案例的边界不同：资料支持一般原则，不说明某句台词已通过实验验证。所有人物、对话、选项和例子为本站原创；不复制付费课程、量表或现代著作段落。

资料包括：爱荷华大学的倾听资源、西澳卫生部门的坚定表达、UNICEF亲子沟通、CCL具体反馈、Gottman的温和开场与修复尝试、俄亥俄州立大学关于道歉的研究介绍、love is respect关系边界和StopBullying.gov反欺凌教育。逐题引用从 `data.js` 映射到来源名称、资料类型、支持范围与链接，核对日期2026-11-02。Ohio State所述研究采用假设情境，不能推出所有现实道歉都有效。

这里不教操控、奉承交换、不讲“保证反败为胜”。善于表达有时能减轻误会，但不能控制别人。伴侣场景强调爱和具体分担；拒绝保留界限；亲子用适龄语言；遇到暴力、威胁或欺凌先保护安全并求助，不让受伤害者负责哄好施害者。个体化医疗、法律、财务与安全判断不由本页替代。

## 操作、手机与隐私

分类、搜索、成人/亲子筛选、收藏、未读、随机和前后题；字号18/20/22可切换。手机目录初始收起，选择后直接定位场景标题，答案展开后定位解析。普通文字正常滑页，不全局禁用手势或浏览器缩放；主要按钮至少44px。键盘可选题和操作。

`family-lab-social.v1` 仅保存收藏和看过的场景编号；导入校验、合并去重、拒绝未知编号与跨馆文件，不覆盖其他馆。清空需要确认，存储被禁用时明确提示。选择和“自己练说”不写入本地记录、不上传；练说在换题/刷新时清空。复制只在点击时请求剪贴板，受阻时提供手动选择，不冒报成功。全站脚本和正文本地提供，只有主动点资料链接才联网。

- `node --test tests/social.test.cjs`：48条结构、8类、选项与相关概念、关键语义边界、资料范围、筛选与记录安全。

- 逐题逐选项核对，检查默认隐藏、直接学习、切题重置、全部解释和跟进回应、来源、记录/导入导出/清空、剪贴板成功与受阻分支、存储失败、320—1440px布局、可信手机点按与滑页。
