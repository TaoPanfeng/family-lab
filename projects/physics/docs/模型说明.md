# 模型、适用条件与复核点

本文件说明程序实际计算什么。模型实现位于 `src/physics.js`，画面只读取结果。未做独立物理测量，自动化测试主要验证实现、关系、边界与参考数值。

## 1. 运动、力与能量

| 实验 | 实际计算 | 限制 |
|---|---|---|
| 速度 | v=s/t，x=vt | 单向匀速，位移大小等于路程；不包含往返 |
| 加速度 | v=v₀+at，x=v₀t+at²/2 | a 恒定；允许速度变负表示反向 |
| 合力 | f=min(F, μmg)，a=(F−f)/m | 从静止向右施力；最大静摩擦系数与动摩擦系数设为同一值 |
| 做功 | W=Fs cosθ，P平均=W/Δt | 规定位移；只算指定恒力的功，不视作全部合功 |
| 无阻力落体 | v²=2gh，t=√(2h/g) | 由静止开始，g 恒定，落体不在液体中 |
| 平方阻力落体 | m·dv/dt=mg−cv² | 两球取同一 c；忽略空气浮力、冲击和反弹 |

平方阻力使用解析解而非帧率相关积分：

```text
v(t)=sqrt(mg/c) tanh(sqrt(gc/m)t)
s(t)=(m/c) ln cosh(sqrt(gc/m)t)
t_hit=sqrt(m/(gc)) acosh(exp(ch/m))
```

实现使用稳定的 `logCosh` 和大参数分支，避免极轻物体和高阻力时指数溢出。触地后停止位置变化、保留触地前速度用于比较，不模拟撞击后的状态。

## 2. 出流：速度、流量和排空不能混用

开放水箱和出口处在同一大气压。孔截面远小于水箱截面，忽略水面速度，采用准稳态近似。

```text
A孔=π(d/2)²
v理想=√(2gh)
v射流=Cv·v理想
A射流=Cc·A孔
Q=Cc·A孔·v射流=Cd·A孔·√(2gh)
Cd=Cv·Cc
```

理想：Cv=Cc=1。示例损失：Cv=0.97，Cc=0.64，Cd=0.6208。速度系数和流量系数不是同一个量。

液体密度采用固定教学值：水 1000、示例油 800、水银 13600 kg/m³。切换液体只改变密度相关的压强/浮力；没有材料相关的黏度、表面张力或损失系数数据库，不用于预测三种真实液体的排放差异。

恒水位模式假设外部补液。排水模式：

```text
sqrt(h(t))=max[0,sqrt(h₀)−Cd·A孔·sqrt(2g)·t/(2A箱)]
排出体积=A箱(h₀−h(t))
```

界面计算体积流量时将 m³/s 转成 L/s。孔径先从 mm 转成 m。最长播放区间截到一天；非常慢的排水不承诺在区间内排空，可查看当前状态或调大孔径。

落球始终由初始高度 h₀ 释放。液面下降后，当前出流对应 h(t)，与落球初始高度的末速度不再是同一条件；文案和读数对此作了区分。

## 3. 大气与沸点

取标准对流层公式，海拔范围 0–9000 m：

```text
T=288.15−0.0065h       [K]
p=101325·(T/288.15)^[9.80665/(287.05287·0.0065)]  [Pa]
rho_air=p/(287.05287T)
```

这是标准干燥大气，不是实时气象。将几何高度近似为位势高度，g 取 9.80665 m/s²；不用于登山、飞行、呼吸或人体承压判断。平板单面的 pA，不是人体/平板两侧的净力。

水的饱和蒸气压采用 IAPWS SR1-86(1992) 式 (1)，T 为 K：

```text
Tc=647.096 K, Pc=22.064 MPa, τ=1−T/Tc
ln(p/Pc)=(Tc/T)·Σ(ai·τ^bi)
a=[−7.85951783, 1.84408259, −11.7866497, 22.6807411, −15.9618719, 1.80122502]
b=[1,1.5,3,3.5,4,7.5]
```

函数限制在三相点至临界点，反求沸点使用 64 次二分。界面给定水温为 20–105°C；不是求解加热功率、升温时间或相变耗热。

表面沸腾条件比较 `p饱和(T)` 与 `p外界`。假想气泡的额外条件为：

```text
p需要=p外界+1000·g·d+2γ/r，γ=0.06 N/m
```

d 从 cm 转 m，r 从 mm 转 m。定密度、定表面张力均为教学估计；气泡轨迹、密度、大小与数量不代表真实测量或成核动力学。超过当地沸点的设定仅表示这种均匀敞口液态存在不稳定趋势。

复核点：标准气压下沸点约 99.9743°C，5000 m 的本模型约 83.2546°C。不是声称所有海平面和所有 5000 m 地点有这些精确数值。

## 4. 静水压、气压计和浮力

静水压采用 `p绝对=p上方+ρgh`；额外压力为 `ρghA`。受压面积 cm² 转 m²。

气压计采用 `h=(p外−p顶)/(ρg)`。装置是假设足够长、管顶密封、底部与外部液池连通且已经建立液柱的终态。可选择加入 20°C 水蒸气压；示例油/水银的蒸气压未建模。额外空气压强取外界压强的百分比，总顶部压强限制为不超过外界。

标准气压、理想真空、ρ水=1000 时，水柱高度约 10.3323 m；ρ汞=13600 时约 0.75965 m。普通杯子倒扣、纸片托水、密封与表面张力的稳定性问题不是这个模型。

浮力采用 `F浮=ρ液gV排`。给定体积为 L，计算密度时转 m³。自由漂浮时实际浮力等于重力；全浸没最大浮力另列。所需浸没比例大于 100% 意味着不能自由漂浮，不是把物体画出超过自身的体积。

## 5. 机械、振动与电路

杠杆：水平杆、向下重力、垂直力臂，比较 `m左gL左` 与 `m右gL右`。显示的是转动趋势，不通过造一个无依据的倾角假装求解动态。

滑轮：n=1、2、4 段竖直承重绳，慢速匀速提升。`F拉=mg/(nη)`，`s拉=nh`，`W输入=mgh/η`。η 为总效率，统一表示损耗；不是滑轮轴承力学仿真。2 段单动滑轮的自由端向上拉；4 段组合有导向定滑轮，自由端向下拉。不能只数滑轮个数判断省力倍数。

弹簧：水平、线性、无阻尼，`x=Acos(√(k/m)t)`，`F=−kx`，`E=kA²/2`。不模拟压缩极限或塑性形变。

单摆：无阻尼，角度 1–10°，使用小角度线性模型 `T≈2π√(L/g)`。动能和势能均按同一线性近似计算，不能把这组能量结果当成大角度的精确机械能。

电路：理想电源，两个定温欧姆电阻，串联/并联与开关。`I=U/R等效`，`P=UI`，`E=PΔt`。粒子表示约定电流方向，不表示电子漂移速度或电信号传播速度。不模拟温升、短路、电池内阻或真实接线风险。
