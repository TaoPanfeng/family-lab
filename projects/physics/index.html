BEFORE WE EXPLORE

把现象看清，把边界留住

1. 从一个问题出发

选实验 → 先猜 → 拖动一个参数或用任务按钮 → 看变化 → 展开公式 → 用自己的话记录。研究模式默认展开公式，儿童与亲子模式先展示问题。亲子共玩可交换驾驶员。

2. 让两个条件同时出现

点击「固定当前为对照 A」，再只改一个参数。A 保持原参数，B 是当前试调；两边共用一个模拟时间，各自到达终点后定格。参数改变会暂停并回到起点，避免悄悄改变运动历史。两边尺寸会优先使用共同量程；粒子、球与器材大小常为教学放大，不拿屏幕尺子代替数值。

3. 公式关系不是一串魔法推导

定义、实验定律、推导、近似是不同的。不能从 v=Δx/Δt 单凭代数就推出牛顿定律。每个实验都标出所需条件和来源；「公式地图」显示概念联系，不把所有箭头冒充严格推导。

模型内观察，不是独立实测。

动画由这些公式和模型驱动，用来理解关系、提出预测；不能反过来将动画当成公式已经被独立实验验证的证据。数值精细也不代表现实测量同样精确。

4. 记录只在你的设备里

无需联网、登录或后端；没有遥测、远程字体或在线 AI 接口。只有主动打开来源链接时才联网。浏览器允许时自动暂存；清理数据、换浏览器、移动文件或私密模式都可能让记录不可见。「我的发现 → 导出全部备份」是可靠的带走方式。浏览器禁止存储时会明确提醒，不会假装保存成功。

5. 只把安全的好奇心带到现实

水银、高处抛物、高压水柱、热水蒸气、密闭加热、重物悬挂和电路接线均以屏幕模拟为主。不接触水银，不拆器具，不接市电，不短接电池。项目不是工程设计、健康建议、登山指南或安全认证。

6. 播放、暂停与迁移

空格播放／暂停，R 回到起点；输入框与弹窗内不会抢按键。可拖动时间轴，也可选 0.25×–1000×；切到后台会暂停。某些实验展示的是静力平衡或参数关系，播放只让示意粒子运动，不代表系统经历了真实加热或建立平衡的过程。

电脑 Chrome／Edge 为优先入口。完整解压后打开 index.html；本机策略限制时，可按 README 使用可选本机服务器。不要关闭浏览器安全防护。
