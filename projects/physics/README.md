# 观物 · 亲子物理实验室 v1.0

**不是背一串公式，而是把现象、条件、变量和公式连起来。**

离线网页，16 个可调实验，3 种探索模式。正常使用不需要 Node、npm、Java、账号、API Key 或联网。

## 1. 先打开，再动手

把 ZIP **完整解压**到普通文件夹，双击 `index.html`，使用电脑 Chrome / Edge 打开。Windows 也可以双击 `Start.cmd`，它仅调用默认浏览器打开同一个 HTML。

首页是「水流与落体」，默认水头 10 m。试试：**先猜一猜 → 按任务只改小孔直径 → 观察 A/B → 展开解释 → 用自己的话记录。**

单文件 `index.html` 已包含样式、计算、动画和课程内容，不从 CDN 下载资源。不必运行构建，不要在压缩包预览器内直接打开。

若设备或单位策略不允许直接打开本地 HTML，不要关闭浏览器安全保护。已有 Node.js 18 或以上时，可运行 `Start-server.cmd`，或在项目目录执行：

```bash
node tools/serve.cjs
```

打开终端显示的本机地址，通常是 `http://127.0.0.1:8789`。服务只绑定本机，端口占用时顺延，按 Ctrl+C 结束。它不是公网服务器，也不会自动改变防火墙。首次入口依然优先用 HTML。

## 2. 里面有什么

| 领域 | 可操作实验 |
|---|---|
| 运动、力、能量（5） | 路程与速度、速度怎样改变、力与小车、做功与功率、落体与能量 |
| 流体、气压、热（6） | 水流与落体、水下的压强、登山与大气压、高山上的沸水、倒置液柱与气压、浮力与沉浮 |
| 机械（2） | 杠杆与平衡、滑轮与省力 |
| 振动（2） | 弹簧与储能、单摆与节奏 |
| 电路（1） | 电路与能量 |

名称以界面为准，每个实验都有参数、4 个数值读数、原理分步、关系曲线、一道先猜再试任务、条件边界和资料来源。

**三种模式**：我来研究默认展开公式；小小探索员先用孩子听得懂的问题开场；亲子共玩增加“谁来操作、谁来提问”的角色切换。模式共用同一物理模型，不为孩子编造另一套结论。儿童模式不锁死高级内容，大人可以陪着展开。

**A/B 对照**：固定当前为 A，之后只改 B。两边共享模拟时间、分别在自身终点定格。改变多个参数会提醒“不再是单变量对照”。改变参数自动暂停并回到起点，避免把不同初始条件混成一段运动史。

**公式地图**：3 条学习路径，明确写出定义、定律、推导、近似、类比。不是把所有箭头冒充数学推导。

**亲手操作**：拖动滑条、输入数字、切换选项。水流的初始水头、水压探测深度、杠杆力臂，还能直接拖画面中的圆点；其他参数用旁边控件修改。

**播放**：支持暂停、重来、时间轴、0.25× 至 1000×。空格播放/暂停，R 回起点；输入框和弹窗内不抢快捷键。切到后台自动暂停。静力实验和沸点判断不是动力学或加热过程，播放主要用于示意。

**带走发现**：保存现场 PNG；导出曲线 CSV；发现记录可增删改、恢复参数与 A/B 时刻、导入/导出 JSON。删除需要确认，也能撤销最近一次删除。导入先完整验证，出错不覆盖原记录，同编号保留当前记录，最多 100 条、单个备份最多 2 MB。

## 3. 给爸爸与小探索员的第一课

先问：“**孔变大，水一定会跑得更快吗？**”别急着讲公式。让孩子选自己的猜想，然后只把孔直径从 10 改成 20 mm。

模型读数会显示：理想条件下速度没有变，流量变成四倍。接着再追问：“是每滴水跑得更快，还是能一起出去的水更多？”最后看 `Q=Av` 与圆面积公式。孩子不需要先会开平方，先说清“谁变了、谁没变”即可。

更完整的共玩流程见 `docs/亲子共玩指南.md`。

## 4. 请先知道这些边界

- 落球在桶**旁边**，不是在水中下沉；相同高度的末速度相等，只针对理想出流和无阻力落体。
- 液体选项改变密度，不是不同真实液体的完整流动仿真。损失系数只用于展示差异，没有按水、油或水银标定黏度。
- 大气压来自标准大气近似；沸点采用 IAPWS 饱和压关系反求。气泡数量和运动是示意，不是 CFD、实际加热或成核仿真。
- 气压计是“已经建立液柱”的静力终态，不是普通空杯倒扣便可得到真空。
- 杠杆是静力分析；滑轮为慢速提升；单摆是 1–10° 小角度模型。模型未包含的效应，都不靠动画偷偷补出来。
- **水银仅屏幕模拟**。不购买、接触、拆开水银器具；不做高处抛物、高压水柱、密闭加热、危险悬挂或市电实验。

**动画由模型生成，不是独立实测。** 数值显示到小数点后两位，不等于现实有同样的测量精度。

## 5. 记录放在哪里

浏览器允许时，记录和上次现场保存在本机 `localStorage`，不会上传。数据被清理、换浏览器、私密模式、移动文件或使用另一个地址，都可能使旧记录不可见。

当浏览器禁止持久存储时，界面会明确显示“仅本次暂存”。**离开前到“我的发现 → 导出全部备份”保存 JSON。** PNG 和 CSV 不含完整发现记录，不能代替 JSON 备份。

只有主动点击“资料来源”链接时才联网。链接失效不影响实验运行。项目没有实时 AI 对话、语音识别、云同步或自动获取天气，不把未实现的能力放在界面里。

## 6. 代码与复验

```text
index.html                 可直接打开的离线成品
Start.cmd                  Windows 默认浏览器入口
Start-server.cmd           可选本机服务入口，需要 Node
Build.cmd                  可选重建入口，需要 Node
src/catalog.js             参数定义、16 个实验课程、路线和来源
src/physics.js             纯计算、参数校验、备份校验
src/scene.js               Canvas 画面与关系曲线
src/app.js                 交互状态、对照、记录、导出
src/index.template.html    HTML 外壳
assets/style.css           响应式样式，使用系统字体
tools/build.cjs            零依赖确定性构建
tools/serve.cjs           仅本机静态服务
tests/                    Node 测试与 Playwright 浏览器测试
docs/                     设计分析、模型说明、共玩指南、测试报告
previews/                 实际页面截图
BUILD_MANIFEST.json       构建大小和 SHA-256
```

开发时修改 `src/` 和 `assets/`，然后运行：

```bash
node tools/build.cjs
node --test tests/physics.test.cjs tests/server.test.cjs
```

不要只修改生成的 `index.html`，否则下次构建会覆盖。没有运行时第三方依赖，不需要 `npm install`。

浏览器复验是开发可选项，需要 Python、Playwright 和 Chromium；入口 `python tests/browser_test.py`，可用 `GW_BROWSER` 指定浏览器。测试依赖不随包附带，也不影响普通使用。

实际通过项、环境限制和没有测试的设备见 `docs/测试报告.md`。**不宣称做过 Windows/Edge 真机或手机真机测试。** 本次环境的 `file://` 导航被管理策略阻止；已测试相同成品 HTML 的交互，另测了本机 HTTP 服务，未绕过策略。

## 7. 为何不是全 3D

这版有意用剖面式二维实验台：液柱高度、合力方向、力臂与承重绳段比“能转动相机”更重要。优先让变量、公式和画面一致，而不是堆一个漂亮但含糊的物理世界。后续扩展可以增加独立实验，但需要同时补计算、内容、边界和测试。
