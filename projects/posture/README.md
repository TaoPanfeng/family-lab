# 身有度 · 行住坐卧实验室

**一个把「姿势 × 场景 × 身材 × 支撑」放在一起探索的离线交互项目。**

不是一张“标准坐姿图”，也不是医疗处方。先理解关系，再试调家具和支撑，最后记录自己的感受。

## 1. 直接打开

1. **把 ZIP 解压到普通文件夹**，不要直接在压缩包预览窗口中运行。
2. 用电脑上的 Chrome 或 Edge 打开 **`index.html`**。Windows 也可双击 `Start.cmd`，它会调用默认浏览器。
3. 先选左侧姿势，再改右侧参数。鼠标拖动中间模型可旋转，滚轮可缩放。

`index.html` 已内置代码、样式和图标，运行不需要联网、安装 npm 包、启动 Java 服务或登录账号。只有点击「参考依据」中的外部原文时才需要网络。当前版优先考虑桌面浏览器；手机布局也已做适配。

> 浏览器或公司策略可能禁止打开本地文件。项目附有可选本机服务器；见第 6 节。请遵守设备管理规则，不要绕过组织策略。

## 2. 这版可以做什么

| 模块 | 已实现内容 |
| --- | --- |
| 姿势库 | 15 个条目，行／住／坐／卧分类、关键词与别名搜索、卡片与紧凑列表、收藏 |
| 3D 场景 | 参数化人体、工位、长椅、地垫、床垫；旋转、缩放、四个视角、步骤高亮、部位点击 |
| 工位试调 | 身高 140–205 cm；椅面、输入面、屏幕上缘、视距、靠背夹角、脚踏可调 |
| 尺寸校准 | 可填写实际腘窝高、坐姿眼高、坐姿肘高；可关闭身高变化时的家具联动 |
| 睡眠支撑 | 6 个睡姿条目；床垫相对软硬 1–5 档、受压后枕高、可选膝间／膝下／下腹支撑 |
| 操作指导 | 总计 82 个定位与自查步骤，含左右手安排、优点、局限、即时自查、参考资料 |
| 轻量辅助 | 自然呼吸默认；清醒时可选轻柔节拍；自定义换姿提醒；可暂停的步态演示 |
| 个人方案 | 命名、备注、本机保存、应用、删除、双方案 3D 对照、差异参数显示 |
| 带走记录 | JSON 导入／导出、当前 3D 视图 PNG、浏览器打印姿势卡／用户选择另存 PDF |

**15 个条目：**电脑工位坐姿、公园长椅坐姿、椅上端坐（正坐）、跪坐（传统正坐）、垫上简易盘坐、自然站立、站立工位、松静站立、自然行走、左侧卧、右侧卧、仰卧、俯卧、蜷曲侧卧、吉祥卧（唐僧睡）。

「住」在本项目中作为站立、静立分类；「正坐」同时保留椅上端坐和传统跪坐两种语境，不混为一谈。

## 3. 建议先试的两个完整流程

### 工位流程

选「电脑工位坐姿」→ 输入自己的身高 → 打开「实际尺寸校准」并填写实测值 → 试调椅面、输入面、屏幕 → 按步骤检查双脚、靠背、左手、右手和视线 → 保存「工位·调整前」→ 再调一个参数 → 另存「工位·调整后」→ 在「我的方案」选中两个方案对照。

例如，默认 **170 cm 只是教学示例，不是你的已知身高**。界面会给出比例推算的椅高起点，而不是宣布某个高度一定正确。实测填写的是：

- **腘窝高**：穿常用鞋、脚掌落地，从地面量到膝后折痕。
- **坐姿眼高**：从受压后的椅面量到眼部水平线，不是从地面量。
- **坐姿肘高**：肩放松、前臂近水平，从椅面量到肘下方。

### 睡姿流程

搜索「唐僧睡」→ 选择「吉祥卧·唐僧睡」→ 调整相对床垫硬度与示意枕高 → 点第 4 步看右手位置，第 5 步看左手位置 → 切换「优劣与自查」→ 记录自己的观察。

这里采用**枕头承头的舒适改良版**，不是要求用手掌撑头的影视造型，也不作传统动作的正统性认证。

## 4. 必须知道的边界

**身高不等于完整身材。** 产品内的简化比例公开列在「使用与依据」及 `docs/参考与边界.md`。它们不是官方人体测量公式。实测校准目前只影响坐姿相关起点；站姿仍按身高比例示意。家具尺寸最终需要现场确认。

**床垫档位不是商品标准，3D 凹陷不是压力检测。** 模型没有体重、材料、组织力学、真实接触与床品变形数据；不计算压强、健康评分或最适合你的枕高，也不据此提供购买处方。

**模型展示完成姿势，不播放安全起卧转移动作。** 步骤用于解释先关注哪里、如何定位和自查；人体为简化几何模型，部分极端参数下会有穿插或近似接触，不适合用作精确角度测量。

**左右以模型本人为准。** 不是屏幕左边就一定是左手。涉及手臂的步骤会显示 L／R 标签；可打开尺寸标注并旋转观察。

**呼吸节拍是可选 UI 工具，不是每种姿势的“正确呼吸频率”。** 默认自然呼吸；不屏息、不强迫深吸，不控制睡着后的呼吸。计时器和步态节拍也不是训练目标。

本版只面向一般成人教育，不将成人比例与步骤直接套用于儿童、孕期、术后或活动受限人群。出现疼痛、麻木、眩晕或呼吸不适，先停止并调整；持续、明显或反复症状应寻求专业评估。不能用姿势调整替代已开具的治疗。胸痛、严重呼吸困难等急症应及时寻求当地急救。

## 5. 保存、备份与隐私

应用不发送身体尺寸、备注或方案，不包含统计脚本或远程字体。通常使用浏览器 `localStorage` 保存；浏览器拒绝存储时，会提示只能暂存于本次会话。

**「我的方案 → 导出全部方案」是最重要的备份入口。** 清理浏览器、隐私模式、换浏览器或移动 HTML 位置，可能让本地记录丢失或不可见。JSON 含尺寸与备注，请自行妥善保管。

每个浏览器记录最多 100 个方案。导入限制为 2 MB，校验版本、条目、数值与数量，跳过完全重复方案；格式损坏时不改变现有方案。备份范围是**已保存方案和收藏**，不包含尚未另存的当前试调、计时器或临时自查勾选。

## 6. 开发与可选本机服务

只使用原生 HTML、CSS、JavaScript 和浏览器绘图接口。当前任务不需要用户系统或多人同步，因此没有增加 Spring Boot、数据库等运行负担。

有 Node.js 18 或以上环境时，在项目目录运行：

```bash
# 编辑 src/、assets/ 或 dev.html 后，重新生成独立入口
node build.cjs

# 计算、导入安全与可选本机服务测试；无需安装依赖
npm test

# 可选：启动仅限本机的静态服务
npm start
```

然后访问 `http://127.0.0.1:8787`。端口占用时设置 `PORT`：

```powershell
# PowerShell
$env:PORT=8788
node server.cjs
```

Windows CMD 用 `set PORT=8788`。服务器只监听 `127.0.0.1`，不是给局域网或公网提供账号／同步服务。`dev.html` 是可读开发入口；**不要直接修改生成后的 index.html 再忘记同步源码**。

可选浏览器测试需要单独安装测试工具；普通用户运行应用不需要：

```bash
python -m pip install playwright
python -m playwright install chromium
python tests/browser_smoke.py
```

指定本机浏览器路径可用 `--browser`。`--inject` 为受限测试环境专用，详见测试报告，不等于真实本地文件启动验证。
