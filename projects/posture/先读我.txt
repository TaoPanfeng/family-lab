身有度 · 行住坐卧实验室 v1.0

【打开】
1. 先完整解压 ZIP 到普通文件夹。
2. 用 Chrome 或 Edge 打开 index.html；Windows 也可以双击 Start.cmd。
3. 左侧选姿势，右侧调尺寸，中间拖动模型。无需 Java、npm 安装或登录。

【建议先试】
电脑工位 → 输入身高 → 实际尺寸校准 → 保存方案。
搜索“唐僧睡” → 点步骤看左右手 → 调整示意枕头和床垫。
我的方案 → 勾选两份 → 并排对照。

【备份】
在“我的方案”点“导出全部方案”。清理浏览器、换浏览器或移动文件可能影响本地记录。
JSON 只备份已保存方案和收藏，没点保存的试调不包括在内。

【边界】
这是一般成人的姿势教育示意，不是医疗软件。
身高只给起点；床垫凹陷是示意；模型不是安全起卧动作动画。
疼痛、麻木、头晕或呼吸不适先停止，反复或明显症状寻求专业评估。
