## 2. 实际环境与方法

Linux 容器，Node 22.16.0，Python 3.13.5，Chromium 144.0.7559.96，Playwright Python。

浏览器管理策略拒绝 `file://` 和本机 HTTP 导航。没有修改或绕过该策略。本次通过 `page.set_content()` 注入**构建后的同一独立 HTML** 验证 UI 和运行逻辑。

该 Chromium 无法提供 WebGL 上下文，因此本次实际测试的是**Canvas 软件三维深度绘制路径**。15 个姿势以及步骤关注部位都构建了非空、有限数值的三维顶点，且在页面上实际绘制。未据此声称硬件 WebGL 已通过实测。

正常保存与新页面恢复使用测试专用内存 `localStorage` 替身。另开不装替身的注入页面，验证原生存储拒绝时的提示和会话内保存能力。替身不在交付 `index.html` 或应用源码中，只在浏览器测试脚本里。

本机服务器用 Node HTTP 客户端直接请求进行验证；这个结果不等于受限浏览器内的 localhost 导航已验证。

## 3. 浏览器覆盖的完整流程

1. 启动、15 条目列表、四大类、别名搜索（唐僧睡／正坐）、空结果恢复、收藏、卡片与紧凑列表。
2. 每个姿势的每个步骤、优劣与自查、来源显示；总计 82 个步骤。通过不能理解为动作医学正确性验证。
3. 身高、个人实测、家具联动开关、手动参数、空输入保留、越界钳制与失配提示。
4. 相机预设、键盘与指针拖动操作、尺寸标注、床垫软硬变化的画面差异、枕高及额外支撑、左右手标签。
5. 保存两份方案、用户文本 HTML 转义、并排双三维场景、参数差异、关闭对照与应用恢复。
6. 实际下载 JSON、重复跳过、无效数值／损坏 JSON 不改变现有数据、有效增量导入与确认删除。
7. 实际下载 PNG、校验 PNG 签名和宽高；打印卡内容生成与 `window.print` 调用（系统打印弹窗替换成计数器）。
8. 自愿呼吸节拍启停、换姿计时启动／到期（测试时钟前移）、步态连续重绘与暂停。
9. 13 条来源及安全说明、多个视口无横向溢出、存储恢复逻辑与存储被拒的备用流程。

鼠标部位点击、双指手势等有实现，但不把“调用过相关界面”夸大为每个像素／每种设备的命中率测试。手机触控和辅助技术仍需要目标设备专项验收。

## 4. 已发现并修复

- 未知备份字段 `__proto__` 触发继承属性误判：改为 own-property 白名单检查；回归通过。
- Canvas 仅三角形排序时部分交叠遮挡不正确：改为逐像素 Z-buffer。
- 床垫顶面与形变曲面重叠产生条纹：移除底层盒体上表面，只保留形变曲面。
- 对照弹窗快速关闭时的延后创建风险：增加弹窗开启状态检查及关闭清理。
- 调整工位初始视角与侧卧支撑几何，重新查看实际页面截图。

## 5. 未验证与剩余边界

**未实测：**Windows/Edge 双击本地文件、Windows 批处理启动器、真实 file-origin 的跨重启磁盘持久化、硬件 WebGL、系统打印设备、iOS/Android 真机、所有浏览器、屏幕阅读器完整流程、性能压力测试。

**打印：**验证了卡片 HTML 和调用，不声称实际打印机或操作系统 PDF 对话框已验证。

**模型：**简化人体与支撑关系，没有人体测量数据库、碰撞约束、材料仿真、精确压力或个体诊断。极端参数下的形体接触和手脚位置只是近似。没有起卧转移连续动画。

**内容：**已查阅列出的公开资料并区分文化来源，但没有临床专家审稿、临床试验或疗效验证。项目是教育软件，不能因软件测试通过就推导出医学有效性。
