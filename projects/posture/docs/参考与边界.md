# 参考资料与模型边界

资料核对日期：2026-10-16。下列为原始研究、机构教育材料及单独标注的文化资料。外部原文需联网。步骤由本项目重新编排，不是逐字转载，不代表机构认可本项目。

## 1. 尺寸计算的性质

应用中的比例是用于构建参数化示意的产品假设，不是临床处方、人体测量数据库或统计置信区间：

| 参数 | 未校准时的简化起点 |
| --- | --- |
| 腘窝高 | 身高 × 0.25 |
| 坐姿眼高（自椅面） | 身高 × 0.44 |
| 坐姿肘高（自椅面） | 身高 × 0.145 |
| 站姿眼高 | 身高 × 0.936 |
| 站姿肘高 | 身高 × 0.63 |
| 椅高默认值 | 腘窝高 − 1 cm |
| 椅高试调范围 | 腘窝高 − 2 cm 至腘窝高 |
| 坐姿输入面起点 | 椅面高度 + 坐姿肘高 |
| 屏幕上缘示例 | 当前眼高 − 2 cm |

屏幕中心俯视角使用一个固定高约 32 cm 的演示屏幕，按 `atan2(眼高 − (屏幕上缘 − 16), 屏距)` 计算。该值描述模型几何关系，不校准真实屏幕尺寸、头部转动、视力或镜片。

提示中的椅高差、眼高差、肘高差阈值也是产品内的试调规则，并非医学诊断界限。显示绿色只表示接近界面规则，不是健康认证。

## 2. 床垫、枕头与传统睡姿

床垫 1–5 档没有可映射到品牌产品的国家／行业等级，也没有加载真实人体或材料数据。下陷用高斯形变画面解释相对差异，不输出压强，不能确定个人最合适的硬度。

枕高是受压后高度的示意参数，各睡姿默认值只是初始画面。唐僧睡以右侧微屈形态为文化识别基础，采用头枕承头的改良版，不把手掌承重、按耳按穴或固定舌位作为要求。

本项目不声称所有侧卧都优于所有仰卧，也不声称中等硬度适合所有人。研究结果需要对应研究人群和结局，不作无限外推。

## 3. 呼吸、步态与适用人群

自然呼吸为默认。可选节拍显示的次数每分钟只由 `60 ÷ (吸气秒数 + 呼气秒数)` 得出，不是最优或统一生理频率。没有屏息阶段，不要求配合睡眠、不作疾病治疗。

步频只控制动画速度，没有真实足底碰撞、步态诊断或运动处方。成人参数不用于儿童、孕期、术后或活动受限者的个体指导。

## 4. 资料清单

### 1. OSHA · 工作椅与支撑

**类型：**工作环境指导；**机构／发表载体：**美国职业安全与健康管理局。

脚掌获得支撑；肩部放松；椅背提供合适支撑。并未给出仅由身高决定的唯一椅高。

原文：https://www.osha.gov/etools/computer-workstations/components/chairs

### 2. OSHA · 显示器位置

**类型：**工作环境指导；**机构／发表载体：**美国职业安全与健康管理局。

屏幕上缘在眼平或略低处；常用观看距离约 50–100 cm。应兼顾字号、视力和镜片。

原文：https://www.osha.gov/etools/computer-workstations/components/monitors

### 3. OSHA · 中性工作姿势

**类型：**工作环境指导；**机构／发表载体：**美国职业安全与健康管理局。

手腕与前臂自然对齐，肘靠近身体，双脚有支撑；持续保持同一姿势并不理想。

原文：https://www.osha.gov/etools/computer-workstations/positions

### 4. Mayo Clinic · 办公人体工学

**类型：**患者教育；**机构／发表载体：**Mayo Clinic。

先调整椅子和支撑，再安置输入设备、屏幕与常用物品。

原文：https://www.mayoclinic.org/healthy-lifestyle/adult-health/in-depth/office-ergonomics/art-20046169

### 5. Mayo Clinic · 睡姿与背部舒适

**类型：**患者教育；**机构／发表载体：**Mayo Clinic。

侧卧可在膝间放枕，仰卧可尝试膝下支撑；枕头应支撑颈部。俯卧可能增加背部负担。

原文：https://www.mayoclinic.org/diseases-conditions/back-pain/in-depth/sleeping-positions/art-20546852

### 6. Mayo Clinic · 阻塞性睡眠呼吸暂停

**类型：**患者教育；**机构／发表载体：**Mayo Clinic。

有呼吸暂停或憋醒时应就医；体位调整不能替代已开具的治疗。

原文：https://www.mayoclinic.org/diseases-conditions/obstructive-sleep-apnea/diagnosis-treatment/drc-20352095

### 7. Kovacs 等 · 床垫硬度随机试验（2003）

**类型：**原始研究；**机构／发表载体：**The Lancet / PubMed。

针对慢性非特异性腰痛受试者，中等硬度床垫的部分结局优于硬床垫。不能推导出所有人都应选同一硬度。

原文：https://pubmed.ncbi.nlm.nih.gov/14630439/

### 8. Schuitenmaker 等 · 夜间反流与卧位（2022）

**类型：**原始研究；**机构／发表载体：**American Journal of Gastroenterology / PubMed。

在该研究人群中，左侧卧与较短的夜间食管酸暴露时间相关；不是人人适用的治疗承诺。

原文：https://pubmed.ncbi.nlm.nih.gov/34928874/

### 9. NHS · 温和的呼吸练习

**类型：**患者教育；**机构／发表载体：**英国国家医疗服务体系。

以舒适为限，不用力吸深、不勉强计数。本项目节拍是可选界面工具，不是医疗呼吸处方。

原文：https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/breathing-exercises-for-stress/

### 10. MedlinePlus · 姿势基础

**类型：**健康教育；**机构／发表载体：**美国国家医学图书馆。

静态与动态姿势都需要关注；经常改变位置，维持自然的脊柱曲线，不把“挺直”理解成僵硬。

原文：https://medlineplus.gov/guidetogoodposture.html

### 11. Mayo Clinic · 步行技巧

**类型：**健康教育；**机构／发表载体：**Mayo Clinic。

视线向前，颈肩放松，自然摆臂。步态模型只演示交替迈步，不分析个人步态。

原文：https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/walking/art-20046261

### 12. 灵隐寺 · 吉祥卧的传统描述

**类型：**文化资料（非医学证据）；**机构／发表载体：**灵隐寺。

用于说明吉祥卧的右侧卧文化形态。原文涉及健康效果的说法不作为本项目医学依据；项目采用枕头承头的舒适改良版。

原文：https://www.lingyinsi.org/detail_7315.html

### 13. NHS · 膝关节疼痛

**类型：**患者教育；**机构／发表载体：**英国国家医疗服务体系。

膝部疼痛、肿胀或负重困难不应靠强忍姿势解决；明显症状需要评估。

原文：https://www.nhs.uk/symptoms/knee-pain/
