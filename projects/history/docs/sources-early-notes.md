## 2. 年代口径

1. 正数表示公元，负数表示公元前。没有公元 0 年。未知值使用 `null`，不拿大约活跃年代当作确切出生年。
2. 以年为精度，不足以计算精确生日年龄或精确在位天数。在位跨年的年差是近似跨度，不应一律将首尾两个年份都当成完整一年。
3. 改元年、正式即位年、开始掌实权的年份可能不同。秦始皇只列称皇帝以后的阶段，汉高祖不把汉王阶段混算为帝位，孙权不把接掌江东或称吴王的年份混为称帝年，北魏道武帝帝位从 398 年计。
4. 北周初期最高君主使用“天王”称号，宇文觉、宇文毓的记录在说明中标清；不是说他们都从即位第一天就自称皇帝。
5. 先秦采用的夏商周断代工程年份是一种有依据的年代方案，不等于所有细节都没有学术争议。武丁、西周前期人物的说明均提示约年；出生资料缺失时保留空值。
6. 同一旧历年末可能落在下一公元年。本表主要采用换算后的公元年，避免把不同口径混在同一数轴上。

## 3. 实际做了什么来源核验

本次进行了原典网页访问、篇目核对、关键段落抽读和部分年表交叉核对。**没有对 142 人的每个出生年、每条政策评价进行现代学术专著级的逐项考证。** 数据适合作为有来源提示的家庭学习项目底稿，不宜把软件检查通过说成所有史学争议都已解决。

人物 `sources` 中明确区分：

- **“原典，已抽读／已核对……”**：实际查看了相关段落，用于支持所标明的重点。
- **“目录／复核入口”**：实际访问并核对了书目或篇目归属，供继续阅读。访问目录不代表读完全部帝纪，不可据此声称已验证所有生平细节。
- **“年代表辅助”**：只用于辅助核对顺序、在位范围和跨公元年的差异。不是不加甄别地复制整张网络年表。
- `achievement`、`cost` 和 `child` 为结合通行史实撰写的原创教学概括，不是原史书的逐字译文。“代价”“局限”等涉及解释的表达，应当与记载的事件区分。

## 4. 没有隐藏的范围限制

- 先秦诸侯国各君主并未全收；夏商周所列是精选。夏王系和先秦绝对年表需要另做系统考证，不用网络传说填满空位。
- 孺子婴未正式登上皇帝位，因此没有为公元 6—9 年虚构一段皇帝在位。王莽摄政与新朝帝位分开。
- 更始帝刘玄、建世帝刘盆子属于新亡后汉政权并立的过渡史，未硬塞入西汉或东汉常规帝系。本文件没有单独的“更始／赤眉汉”政权标签。
- 十六国及其他地方短期政权不在本人物文件的完整收录范围；桓楚、侯景汉、西梁等应使用独立政权条目进一步扩展。
- 高绍义是北齐灭亡后的流亡称帝，不表示北齐在原本疆域连续统治至 580 年。
- 北齐任城王高湝只收到传位安排而未完成实际登位，本表不列；曹操、司马懿、司马师、司马昭、高欢、高澄、宇文泰等生前未称帝者也不作为实际皇帝列入。
- 女性、农民、工匠、商人、思想家、官员、将领等是历史不可缺少的主体。本人物文件有意在介绍中提醒团队、普通家庭与战争代价，但它本身仍是君主资料模块，不能代替整个社会史。

## 5. 数据检查结果

对本文件运行了 Python 结构与年代检查及 `node --check`，本次结果：

- 142 个 ID 唯一，23 个朝代标签均在约定范围内；每条具备全部 13 个约定字段。
- 在 Node 的独立 VM 中实际执行数据脚本，成功生成 142 条记录；每条儿童解释均检查为两句。
- 出生、死亡、在位年份均为整数或 `null`，没有公元 0 年。
- 已知出生不晚于死亡、即位不早于出生、退位不晚于死亡，在位起止不倒置。
- `achievement` 与 `cost` 每项均不超过 100 个中文字符；儿童说明、年代说明、标签和来源均非空。
- 所有来源条目有标题，URL 使用 HTTPS；该检查不是联网批量断链检查。
- 有 37 条生年未知、7 条卒年未知，保留原样而未用猜测填补。
- 晋惠帝、晋安帝各有两段在位；并立君主保持时间重叠。

这些检查验证数据结构和内部一致性；原典自身立场、绝对年代分歧、现代推年误差仍需持续研究，不能由程序自动判定。

## 6. 文本使用说明

人物教学短文为本项目原创整理，未整段复制现代百科文章。链接到古籍的原文属于历史资料，古籍数字化页面可能另有校勘、标点和网站授权条款。本项目提供来源链接，不把外部站点的整章内容打包转载；离线使用不需要联网，点击来源继续阅读时需要网络。
