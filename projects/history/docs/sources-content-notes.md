# 历史内容来源、边界与校验记录

核查日期：2026-10-19。本文件对应 `data/content.js`，含 38 个中国朝代或主要政权、38 条事件、19 条世界同期参照，以及 95 个去重的来源入口。

## 1. 内容范围

本项目提供中文亲子教学摘要，观察朝代、人物、事件、普通人生活与世界同期发展。正文用自己的话概括；儿童版是教学改写，不是古人原话。贡献属于当时社会的共同创造，不能全部归功于君主；问题与代价同样要区分个人责任、制度条件、战争与环境。

中国主线覆盖夏至清，并展开三国、南北朝、五代和宋辽夏金。先秦诸侯、十六国、十国、吐蕃、大理、西辽、北元、南明等没有全部扩展为完整君主表；地图和背景提到它们，不代表已穷尽所有政权。世界部分是代表性参照，不是世界通史或所有国家名单。

## 2. 日期规则

1. 负数表示公元前，不设公元 0 年。跨公元前后计算年差时须跳过 0 年。本文件仅提供历史年份，由界面负责显示与跨度换算。
2. 年级时间条只能表达年度范围，不能把终年减始年当作精确周年。出生年、即位年、改元年和追尊称号是不同信息。
3. 夏约前2070—前1600年采用常见断代框架，没有同时代王室档案可逐年确证。二里头与夏的对应存在学术争论。商约前1600年、商周更替前1046年也属于采用的约年方案。
4. 西周前1046—前771；东周王室前770—前256。战国时期延续到前221，周王室灭亡不等于战国立即结束。前256—前221仍有秦与其他诸侯国，并非无人统治。
5. 秦朝前221—前206；此前秦国为诸侯国。长平发生于秦国时期，不是秦帝国时期。西汉以刘邦前206受封汉王作为时间条起点，前202才是其皇帝在位起点。
6. 新9—23；东汉25—220。23—25年有更始等政权，未展开独立条目。
7. 曹魏220—266、西晋266—316采用事件折合公元年份。简表常见265年，与当时农历咸熙二年、泰始元年延续至公元266年初有关。这不是时间差计算错误。
8. 东吴222—280以独立改元为起点，孙权229年称帝。赤壁发生在208—209年之交，此时魏、蜀、吴尚未各自建立皇帝政权。
9. 北魏在534—535年分裂，东魏534年、西魏535年起。本数据北魏结束取535，允许分裂过程的短暂重叠。
10. 唐整体跨度618—907，中间690—705为武周。两条同时显示是为了展开中断，不代表那15年有两个同样控制唐朝核心区的中央王朝。帝位应据人物条目分段查看。
11. 后唐末帝败亡采用公元937年初，后晋在936年已经建立，二者短暂重叠。常见后唐止936是农历年序口径。
12. 辽916以耶律阿保机称帝为起点；后续国号改变不另起时间条。元1271建国号、1279灭南宋最后朝廷，两者不能混用。
13. 明1368—1644为主体政权，南明为后续分支。清1636建号、1644入关；努尔哈赤1616建立的是后金，人物可作为前史附录。1912退位为清主体终点，1917短暂复辟不合并进主时间条。
14. 鸦片战争卡取1840—1842远征主战阶段，并说明1839年已有冲突；太平天国卡以1851金田起事、建号为起点，相关冲突可追溯1850年。史学分期有不同取法。
15. 张骞首次出发有前139、前138年两说，本卡采用前138年并标明异说；造纸卡105年指传统上报记载，不是造纸从无到有的时刻。
16. 世界文明与文化时期多为约年或观察窗口。罗马476年仅为西部传统断点；东罗马继续存在。阿拔斯止于1258年的巴格达时期；奥斯曼延续到1922年，超过中国主线。文艺复兴与工业革命不是国家，也没有全世界统一的起止日。

## 3. 地图位置的含义

事件经纬度是教学定位点，通常代表古战场附近、现代相应城市或线路中的一个节点。古河道、海岸、地名和遗址范围会变化，单个点不等于精确战场，更不代表整个战役的覆盖范围。

张骞以长安出发地为点，玄奘以那烂陀为行旅节点，郑和以太仓为启航节点，大运河以扬州为网络节点。《金刚经》以敦煌出土地为点，不能据此断定它就在该处印制；毕昇活动地点有考证分歧，所以用开封作为时代中心，并非发明地。世界节点也不表示历代固定首都或疆界。

地图多边形、底图和绘制误差由项目地图说明另述。本文件没有提供精确领土 GIS 数据，也不将古代范围作为当代领土主张。

## 4. 叙事与证据

- 大禹等传说、小说演义与可核验材料分开。赤壁借东风、神魔版西游等文学情节不冒称史实。
- 史料中的兵力、伤亡与户籍数字口径可能不同，不把不可靠数字用作精确统计，更不把安史时期户籍下降全部换算成死亡人数。
- 帝王成就与暴力代价分别讨论，不用单一善恶标签代替因果。不同民族和政权均有普通人的生活，不把某一方简化为没有文化的背景。
- 技术有长期积累：蔡伦之前已有纸；868年印本证明当时已有印刷，不证明那一年发明；活字没有立即取代雕版；隋代大运河也并非今天京杭全线原样。
- 来源并非没有错误。博物馆和大学简表可能使用不同分期，个别页面甚至有笔误。本数据明确采用靖康1127、元建号1271等交叉确认年份。通用来源只用于对应范围，不作为全部细节的精确证明。
- “为什么”和讨论问题含教学归纳与分析，不伪称史料原话。日常生活是时代性综合描绘，不虚构有姓名的平民日记，也不声称各地区和各阶层的生活相同。

## 5. 已执行的数据检查

通过 Node.js 实际执行加载 `data/content.js` 并检查：

1. 38个预定政权 ID 完整且唯一；每朝恰有两条贡献、两条代价，并有日常生活、儿童解释、收录范围和来源。
2. 日期为整数、不为 0，起止有序；轨道在 0—3 内，色值符合六位十六进制格式。
3. 事件 ID 唯一，事件类型合法，关联朝代全部存在；地名、参与者、因果、结果、影响与讨论问题均非空。
4. 世界条目起止和坐标有效；事件及世界经纬度都在地球坐标范围内。
5. 所有来源为可解析的 HTTPS 地址，有标题与作用范围。
6. 对公元266年魏晋交替、937年后唐终点、1636年清建号、1127年靖康、1271年元建号设置具体断言。
7. 对全部朝代两两检查，同一轨道不存在非零时间跨度的覆盖。北魏、后晋安排在轨道2，金、元安排在轨道3，清安排在轨道1；轨道仅为排版，不能据此判断正统、强弱或地理归属。

结果：PASS；38朝代、38事件、19世界参照、95来源入口。日常生活段落最短82个字符。

首次验证器曾把“洛阳”这样的两个汉字首都名错误判为过短；已修正验证规则为非空的有效中文地名后复验通过。这是检查器问题，不通过填充地名改变历史事实来迁就检查。

这些检查验证数据结构、关联和关键一致性，不等于全部历史事实已经完成专业学术审稿。界面、可访问性、离线、移动端与压缩包启动测试由项目整体验收另记录。
