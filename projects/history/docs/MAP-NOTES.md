# 地图制作与阅读说明

## 地图回答什么

本项目地图帮助回答：几个政权大致在什么方向？都城、江河与战场有什么位置关系？同一时期是否存在多个政权？不同治理方式为什么不能用同一种实心色块概括？

它不能回答某一年精确边界在哪里、多少平方公里、具体县级隶属如何，也不能作为现代领土主张或历史地图学专业成果。

## 底图与历史内容分开

1. 陆地轮廓使用 Natural Earth 的 `ne_110m_land.geojson`，为不含现代国家边界的自然地理数据。
2. 历史色块由项目以经纬度折线自行概括，只画核心分布和部分联系范围。未描摹受版权保护的历史地图，也未将这些多边形包装成专业数据集。
3. CHGIS 的链接是对历史时空数据、行政层级与证据问题的进一步阅读；**本项目没有下载或使用 CHGIS 的精确行政疆界**。
4. 虚线是概括边缘；斜线表示需要额外说明的联系区或差异治理区，不是统一法律地位符号。区域详情逐一解释其含义。
5. 比较地图时，不能凭色块大小推断国力，也不能据此计算面积。

## 年份联动

主时间轴与地图可以互相切换。主时间轴选择任意年时，地图采用绝对年份距离最近的切片；距离相等时选较早的一帧。界面同时显示主时间轴年份和地图年份，不在切片间假装自动生成真实疆界。

从事件进入地图后，该事件独立高亮并显示自己的年份，即使它不在切片前后55年内，或不是战役。背景地图仍保留其本身年代。点击地图年代或播放下一帧时清除事件特定高亮。

## 地理定位与名称

- 经纬度按 `x=经度，y=-纬度` 的等距矩形概念投影呈现；它不是等面积投影。
- 城市标签采用今人熟悉名称和今城附近坐标，不代表同名古城址跨朝代始终不变。
- 黄河、长江为少量控制点近似线；历史改道没有复原。
- 战役常涉及多个地点甚至多年战线；单个标记只代表约略地区，文字说明比一点坐标更重要。
- 空白地方可能有其他政权、部落、聚落与复杂关系，不表示无人居住或无历史。
