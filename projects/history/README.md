# 观史 · 和孩子一起，看见历史

一份可直接打开、完全离线运行的中文历史互动项目。适合亲子共读，也提供成人深读模式。

## 1. 先打开，再探索

1. **完整解压 ZIP**，不要直接在压缩软件里双击里面的网页。
2. 打开 `history-explorer` 文件夹，双击 **`index.html`**。
3. 建议使用较新的 Edge、Chrome 或 Firefox。Windows 也可双击 `Open-History.bat`。

**普通使用不需要 Java、Node.js、数据库、联网、安装依赖或启动服务。** 所有页面、文字、地图底图和脚本都在压缩包内。点击史料链接时才需要联网。

## 2. 已做好的内容

| 模块 | 内容与用法 |

## 3. 和孩子的第一趟旅行

1. 保持右上角的 **“亲子探索”** 模式，进入“小小史官”。
2. 第一站去秦朝，点 **“放大秦”**。让孩子看看：时间条不长，影响为什么很长？
3. 把年份切到 **250**，打开地图，找到魏、蜀、吴。
4. 再去 **750 年的唐**，认识当时的生活，看看同一时期世界其他地方。
5. 选一个喜欢的人物，也读他的局限。最后写一句：“我原来以为……现在发现……”

不用一次看完。每次一个问题，比一次背下一长串帝王名字更有用。

## 4. 大人可以这样读

切换 **“成人深读”**，先观察人物所处的制度、资源和局势，再评估个人选择。页面将优先展示背景、因果与具体行动；儿童解释仍可在另一模式查看。

例如搜索“文字狱”“纳谏”“一条鞭”，比较相关人物的不同处境；搜索会同时检查本名、称号、标签和主要正文。点击档案里的资料出处，可以继续追查史料。

## 5. 必须读清的几个口径

- **264 是人物档案数，不是“公认的264位皇帝”。** 先秦精选15人，另有秦王子婴、前身政权君主、少数短暂或有争议的帝位。特殊身份在人物说明里注明。
- 秦以后，以本版列出的主要政权实际在位君主为主；**没有声称收齐先秦所有诸侯、十六国、十国、南明、北元和所有地方政权**。
- 朝代时间条与个人称帝起点可能不同，例如刘邦先为汉王，后来称帝；清条从1636建号开始，但人物附录包括后金时期的努尔哈赤。
- 实际公元登位年、农历纪年与改元年可能不同。少数跨年事件和常见教材年表存在一年差异，已在档案备注说明。
- **在位时长和寿命只按已知年份差估算。** 多次在位分别相加，不计算精确月日或周年。未知字段显示“未详”；公元前1年之后为公元1年，没有公元0年。
- 唐的时间条拆分为618—690、705—907，武周独立显示；轨道只为排版，不表示“正统”或地理方位。
- **地图是核心分布与政治关系示意，不是精确历史疆界复原。** 只提供13个离散切片；跳到某事件时会标出该事件的位置与年份，同时明确背景地图切片的年份。
- 城市使用熟悉名称及今城附近位置；河流使用现代大致流路。它们帮助辨向，不代替古城址或历史河道研究。

更详细的范围、来源与不确定性记录见 `docs/`。

## 6. 收藏和手记

收藏、读过的人物、已答对的题目、模式、年份、探索路线进度和笔记保存在当前浏览器的本地存储中，不上传到服务器。

如果浏览器不允许本地文件写入存储，或使用隐私模式、清除站点数据、换浏览器、移动项目文件夹，记录可能无法继续保留。写好手记后可点击 **“导出手记”** 保存为 Markdown 文件；导出也包含收藏标题和学习统计。

## 7. 程序结构

```text
history-explorer/
  index.html               打开入口
  Open-History.bat          Windows 快速打开
  styles.css               响应式样式
  app.js                   页面、地图与全部交互
  core.js                  纯函数：纪年、搜索、数据兼容
  assets/favicon.svg       项目标识
  data/content.js          朝代、事件、同期世界
  data/rulers-early.js     先秦至隋人物
  data/rulers-late.js      唐至清人物
  data/land.js             离线自然陆地轮廓
  data/atlas.js            地图切片与说明
  data/learning.js         亲子路线、思考题与词语
  tests/                   自动化验证
  docs/                    来源说明、地图说明、测试报告
```

所有脚本通过传统相对路径加载，未使用模块导入、接口请求或需要服务器的 `fetch()`。这个选择是为了方便直接双击打开与分享。

## 8. 开发和复测

仅开发测试需要 Node.js 18 或更新版本；普通阅读不需要。

```bash
# 数据和纪年测试：无需安装依赖
npm run test:data

# 完整交互联调：安装锁定的开发测试依赖后执行
npm ci
npm test

# 发布文件、入口引用、脚本语法与离线依赖检查
npm run verify
```

`jsdom` 只用于开发测试，不是页面运行依赖，ZIP 不包含 `node_modules`。

`docs/TEST-REPORT.md` 记录了本次实际执行的验证。DOM 模拟测试不等于真实浏览器渲染测试；本次预览基础设施未能启动，因此未宣称完成真实浏览器、触屏、中文系统输入法或像素级布局验收。

## 9. 内容扩展

资料放在独立数据文件中，每条人物记录都含有 `id`、`dynasty`、`name`、`personal`、`birth`、`death`、`reigns`、`achievement`、`cost`、`child`、`note`、`tags`、`sources`。不详年份用 `null`，不要用0或猜测值填空。

增加朝代或政治并存关系时要调整轨道，并更新覆盖回归测试；增加地图时写清楚快照年份、色块含义、证据和不包含的内容。修改后运行测试，再交付。
