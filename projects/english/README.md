# 英语：从意思到表达

从本目录 `index.html` 进入；无需服务器、联网或账号。

8章32课按“骨架→指代数量→时间→语气视角→扩展→连接→阅读推理→综合表达”建议顺序组织。可以自由跳转，保留原来的位置、拼词、数量三个实验。

每课包含3个主情境、3个迁移情境、2组语义/边界对比、2道有明确目的的选择题，以及开放练说。规则、翻译、词块角色和选项依据默认折叠；挑战提交前收起学习提示，提交后按需核对解释。

两个声明题目都答对，记录该课通过；这不是英语水平认证。开放表达没有自动评分，保存不算通过。

路线保存在 `family-lab.english.path.1`，与原 `family-lab.workshop.english.1` 分开。输入先留在本次内存，明确保存才写入练说；切课会恢复未保存内容，刷新会丢失未保存草稿。路线备份合并保留当前同课保存内容；遇不可读原数据锁写并可导出原文，不自动迁移。
