## 五个独立的食甚核对样本

这里比较的是**全球最大食时刻**，不是每个城市的食甚、初亏 / 复圆，也不是专业食带边界。测试容限人为设为 30 秒，目的是发现明显的时间、坐标或几何错误；它不构成整个 1900—2100 年区间的精度承诺。

| 事件 | NASA 参考 UT | 本程序 UTC 近似 | 差值（本程序减参考） |
|---|---|---|---|
| 2009-07-22 日全食 | 2009-07-22 02:35:18.100 | 2009-07-22 02:35:17.551 | -0.548 秒 |
| 2023-10-14 日环食 | 2023-10-14 17:59:29.500 | 2023-10-14 17:59:31.246 | +1.746 秒 |
| 2024-04-08 日全食 | 2024-04-08 18:17:18.300 | 2024-04-08 18:17:23.627 | +5.327 秒 |
| 2025-03-14 月全食 | 2025-03-14 06:58:41 | 2025-03-14 06:58:48.156 | +7.156 秒 |
| 2025-09-07 月全食 | 2025-09-07 18:11:43 | 2025-09-07 18:11:47.703 | +4.703 秒 |

NASA 月食目录的主时间列是 **TD**，不能直接当 UTC。两条 2025 年月食记录采用来源同一行给出的 ΔT = 75 秒，换算到 UT 后再比较。日食来源提供了明确的 UT 值。NASA 来源与本项目使用不同的星历 / ΔT 模型，本项目还把 UTC 近似为 UT1；这些差异没有被冒充为零。

署名：**Eclipse Predictions by Fred Espenak, NASA's GSFC**。原始 URL 和转换备注保留在 `tests/nasa-reference.json`，来源总表见 `docs/SOURCES.md`。这些测试不表示 NASA 对本项目认可或背书。

## 插值误差，不等于模型总误差

用固定随机种子生成 4,000 个没有参与分段系数拟合的时刻，将本包单精度 Chebyshev 插值与同一个 Moshier 模型的直接计算结果对比。

| 项目 | 太阳 | 月球 |
|---|---:|---:|
| 最大角位置额外残差 | 0.008612 角秒 | 0.011935 角秒 |
| 最大距离额外残差 | 8.873843 km | 0.019912 km |

这些小数只能说明压缩 / 插值新增的偏差，**不能用来声称天体总位置精度达到这一量级，更不能据此承诺食接触精确到秒**。月球边缘地形、地球椭球食带、实时地球自转和精细大气折射未被完整模拟；月食影子采用 2% 大气扩大近似，接触时间可能与专业表相差数分钟。

## 如何复现

```bash
node tools/build.cjs
node tests/test.cjs
python tests/server-test.py
# 已安装 Playwright / Chromium 的 Linux 无显示器环境：
xvfb-run -a env CHROMIUM=/usr/bin/chromium python tests/browser-test.py
```

星历的 4,000 个留出样本可通过 `tools/generate_ephemeris.py` 重新生成，但必须安装对应的可选 Python 科学依赖；普通打开网页不需要这些工具。详见 `docs/DEVELOPMENT.md`。

## 尚不应作出的结论

不能根据上述测试宣称软件已支持精确混合日食沿途分类、专业食带地图、每个地点完整的地平线可见区间、真实大气天气、月面天平动或完整引力动力学。实验参数只构造教学运动学世界；非真实预测。
