日月地 · 时空实验室 V2
=====================

1. 完整解压 ZIP，然后用 Chrome / Edge 打开“日月地实验室.html”。
   Windows 也可双击 Start.cmd。请不要在压缩包预览窗口内启动。
   正常使用不需要安装 Node.js、Python，不需要联网或登录。

2. 首页三个入口：
   自由研究：参数、公式、对照实验；
   小小探索员：先猜，再动手，再用自己的话讲发现；
   亲子共玩：孩子驾驶、爸爸提问，可以交换角色。

3. 推荐第一次：
   亲子共玩 → 四季 → 先各说一个猜想 → 让时间走过几个月。
   A 默认是真实地球，B 是假设地球；只改 B 倾角，不改 A。

4. 顶部可换月相、日月食、四季、影子；底部调时间与速度。
   桌面同步看双视图，窄屏使用两个标签切换。
   手机请向下滑动，探索步骤在主画面下方。
   左上角菜单可找高级视角、图层与原有实验。

5. 重要：手记仅存在这个浏览器，不是云同步。
   请在“探索手记”中“导出全部备份”，换设备再导入 JSON。
   禁用存储/私密窗口/换浏览器/移动 HTML 路径都可能影响记录。
   黄色提示“仅暂存”时，关闭页面之前务必导出。

6. 右侧影子是所选日期的正午，不是当前钟点的全天影子。
   B 地球是教学假设，不是天气/气候预测。
   这是科学教学软件，不是专业食带或观测时间保证。
   看日食请留在屏幕里；现实中不可直接看太阳。

7. 实际测试、未测试范围见 docs/TEST_REPORT.md。
   本次未完成 Windows 实机、真实本地文件导航和手机真机认证。
   本地文件导航在测试环境被管理员策略禁止，没有修改策略。

8. 修改源码：安装 Node.js 18+ 后运行 Build.cmd。
   Start-server.cmd 只是可选本机服务，正常打开 HTML 不需要它。
