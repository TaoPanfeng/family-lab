# 日月地 · 时空实验室 V2

**同一个宇宙，三种探索方式。**

这是在 V1 实际源码基础上的升级：没有替换成几段不相干的动画，也没有删掉原来的日月食、日期、地点与假设实验计算。V2 把它们组织成“自由研究 / 小小探索员 / 亲子共玩”，加入同步双视图、地轴对照、正午立杆实验和可带走的探索手记。

## 1. 打开与运行

1. **先完整解压 ZIP。** 不要在压缩包预览窗口中运行。
2. 用较新的 **Chrome / Edge** 打开根目录的 `日月地实验室.html`。Windows 也可双击 `Start.cmd`，由系统默认浏览器打开。
3. 选择一个探索入口，然后点“月相 / 日月食 / 四季 / 影子”。

日常运行**不需要 Node.js、Python、npm、账号、API Key 或网络**。Three.js、数值星历、贴图和全部代码已嵌入单个 HTML。Node.js 只用于改代码后重新构建，或启动可选本机服务。

初次的月相示范固定在 **2026-10-16 18:00（UTC+8，上海）**，方便看到地平线上方的月亮；这不是自动获取“现在”。点击时间栏“此刻”才跳到设备当前时间。

> 测试环境为 Linux Chromium。实际 Windows 启动、真实 `file://` 导航、真实手机触控没有在本次环境中完成验证。管理员策略禁止本地导航，因此测试执行完整 HTML 的页面内容，而不修改浏览器策略。不要为运行本项目降低浏览器安全设置。

### 收藏与手记的重要说明

浏览器允许时，V2 自动保存最后的探索现场、入口偏好和手记。再次打开会出现“继续上次探索”。这不是云同步；私密窗口、清理数据、换浏览器或改变 HTML 所在位置，都可能无法找回本地记录。`file://` 下的存储行为还取决于具体浏览器。

**可靠的带走方式：右上角“探索手记” → “导出全部备份”。** 新设备打开 V2 后导入这个 JSON。若浏览器禁止存储，画面会明确提示“仅暂存 / 请导出备份”，不会假装已经永久保存。

## 2. 三个入口怎么用

### 自由研究

适合想理解底层原因、控制参数和对照数值的人。右侧可以展开原理、几何关系与公式；高级视角、显示图层、真实地月比放在左上角菜单里，不再把整个屏幕围满控件。

推荐路线：**四季 → 同步双视图 → 把 B 地球扶正 → 时间往前走几个月 → 比较白昼 → 记录猜想与发现。** B 的倾角不会修改 A；默认 A 是真实状态，B 是假设状态。主动在高级实验中修改 A 后，标签会随之标成“假设”，不冒充真实地球。

### 小小探索员

从问题进入，而不是从术语进入。每个主题按以下顺序推进：

**先猜一猜 → 真正改变时间或条件 → 看解释 → 用自己的话写发现 → 保存现场。**

没有选猜想时不会直接跳过；尚未操作时不能冒充已经观察。反馈不使用红色“答错”、分数、排行榜或连续登录奖励。发现卡也不会替孩子填好标准答案。

“听一听”只在点击后使用设备本地中文语音；设备没有可用的本地中文语音时会提示，文字功能不受影响。不会悄悄调用联网配音。

### 亲子共玩

每个主题有明确的父子分工。孩子先当驾驶员，爸爸负责提问，先不要抢着揭晓答案；可以点“交换驾驶员”，换一个人操作。最后让孩子用自己的话当一次小老师，保存共同发现。

这是单设备共同操作，不是远程联机，也不是自动识别是谁碰了屏幕。

## 3. 四个主题与同步双视图

| 主题 | 左侧 | 右侧 | 时间步长 |
|---|---|---|---|
| 月相 | 三维地月空间关系 | 所选地点追踪月亮的画面 | 1 天；时间轴围绕当前时刻展开约 30 天 |
| 日月食 | 真实时间下的空间关系与食影 | 同一时刻、同一地点的日食或月食 | 5 分钟；围绕当前食事件展开 |
| 四季 | A 地球，默认真实状态 | B 地球，只改变倾角的假设状态 | 7 天；按界面时区展开该年 |
| 影子 | 该时刻的三维地球与光照 | 所选日期、地点的**正午**立杆实验 | 7 天；全年比较 |

桌面同时显示两个画面；窄屏使用“太空 / 地面”或“真实 / 假设”标签切换，底层仍共用同一个时刻。手机下方还有探索步骤，需要向下滑动。

“同步双视图 · 开 / 关”可以切回单视图。左上角菜单中的独立“站在地球上”保留自由地面观察。“返回刚才”最多保留 15 个主动跳转现场，恢复时间、地点、任务、主镜头和实验条件；恢复后暂停。

### 四季对照的科学边界

B 地球调整的是黄赤交角，沿用同一时刻的原始轨道信息；它是控制变量的运动学教学实验，不是重新积分一个太阳系。比较的是太阳照射几何与白昼，不是气温、气候或真实天气。

### 正午立杆实验

右侧不是当前钟点的影子动画，而是**界面日期对应的当地太阳上中天附近**。内部迭代求太阳时角约为零，再以该时刻赤纬计算：

```text
正午太阳高度 α ≈ 90° − |纬度 φ − 太阳赤纬 δ|
竖杆影长 L = H / tan α
```

可调杆高 0.1—5 米，或切换上海 / 悉尼进行南北半球比较。只在同一日期内改变钟点，正午结果保持不变；日期的划分使用界面时区，因此跨时区切换到不同日历日期时，右侧正午样本可能变化。太阳在地平线下不输出伪造的有限影长，天顶时影长为零。较大立杆或长影子会为适应画面缩放，并明确标识。忽略杆粗、地形与复杂折射，星历范围边缘的求解时间会被钳制到有效范围。

## 4. 探索手记与导出

点击“记录这个发现”或右上角书签图标，可以填写：标题、原来的猜想、亲眼发现、还想问的问题，以及可选的户外观察。记录包含当前日期、时区、地点、主镜头、图层、假设参数、V2 入口、主题、B 地轴倾角和杆高等。

- 最多 40 条。编辑文字保留原来的场景，不会把旧发现悄悄改成今天的状态。
- “继续现场”恢复原场景，保持暂停；日食 / 月食事件上下文也随记录恢复。
- “发现图”导出带用户文字、时间地点和主画面缩略图的 PNG。长文字自动换行。
- 主画面相机按钮导出当前双视图 PNG，保留两边说明与时间地点。
- “导出全部备份”提供可迁移 JSON。重复导入相同 ID 不重复添加，也不会用旧备份覆盖已有的新文字；合并超出 40 条时拒绝，原记录保持不变。
- 删除需要确认，并可撤销刚才的一条删除。
- 支持导入 V1 `version:1` 场景 JSON。V1 文件没有 V2 对照参数，按当前兼容规则打开；不会凭空恢复 V1 从未保存过的 B 倾角、探索文字等。

导出文件会包含手动选择的经纬度和自己填写的文字，分享给别人前请检查。软件不会申请真实 GPS 定位、上传手记或扫描本地目录。

## 5. 原有天象能力

支持 1900—2100 年范围内的日期输入、固定 UTC 偏移、正放 / 倒放 / 暂停、高速播放、临近日月食减速、观测地点与经纬度、二分二至、月相跳转、真实事件回放、食阶段定位、日偏食 / 全食 / 环食与各类月食、真实 / 示意尺度分离。预设真实事件包括上海 2009 日全食、北美 2024 日全食、2023 日环食、2025 月全食等。

不支持历史时区数据库或自动夏令时。城市选择不会自动替你决定历史时区，请查看时间栏的 UTC 偏移。所有天文状态最终以同一个 UTC 毫秒值驱动。

## 6. 画质、兼容与常见问题

**画面卡顿：** 桌面底部“画质”改为“轻量”，或关闭同步双视图。自动模式会在检测到持续缓慢渲染时降低画质。暂停时按需重绘，旋转、缩放仍可使用；后台页面自动暂停。

**没有 WebGL：** 启动时会尝试二维兼容画面，保留时间、数值、教学流程与手记。二维画面明确标识，不能把它当作完整的三维食影替代品。

**月亮 / 太阳没出现在地面：** 先看地平线状态；“全球发生”和“此地可见”是两回事。可以换时间或地点，不代表页面坏了。

**导出或存储被禁止：** 检查浏览器是否拦截下载；不要清理尚未备份的临时会话。可在允许本地访问的普通浏览器中使用，或已安装 Node.js 时启动可选 `Start-server.cmd`，按控制台地址进入。服务仅监听本机，不会开放给局域网或公网。

**文字不会朗读：** 本地没有中文语音不影响使用；本项目不下载语音包。

**隐私窗口 / 换文件夹后没有记录：** 导入之前导出的 JSON 备份。不要把浏览器存储当作唯一备份。
