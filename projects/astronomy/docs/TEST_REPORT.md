本机 HTTP 检查用 Python `http.client`，验证返回字节、404、路径穿越拒绝及非法 URL 响应；不是浏览器导航测试。

## 3. 这次验证了什么

月相 / 食事件两个视图共享真实时刻；切时区不移动天体；月食追踪对象不会误用太阳；A/B 不互相篡改，绘制高度一致；正午求解与影长边界；儿童预测与真实操作之后才能推进；父子角色切换；手记文字与场景恢复；JSON 下载、校验、合并与新浏览器上下文导入；PNG 实际下载；手机窄视口操作；暂停时减少重绘；非法导入与 HTML 注入防护。

**两个测试方法必须区分：** WebGL 初始化失败使用故障注入，证明兼容分支可以运行；存储适配器夹具使用内存后端，证明旧现场不会被欢迎页覆盖、继续 / 关闭入口能恢复。二者不等于所有真实硬件故障和浏览器本地持久化已经认证。另一个“备份迁移”测试则是真的把下载的 JSON 导入新浏览器上下文。

检查全过程未记录到 JavaScript / WebGL 控制台错误，未发生外部 HTTP(S) 请求。所有截图来自实际运行；截图中的手记文字是自动化测试示例，不是用户或孩子的真实记录。

## 4. 独立全球食甚样本

比较全球最大食附近的搜索时刻，而非逐城接触时刻、精确食带或天气。每个样本容限为 30 秒，只用于发现明显回归，不能据此承诺整个 1900—2100 年区间都有同等精度。

| 事件 | 参考 UT | 本程序 UTC 近似 | 差值 / 秒 |
|---|---|---|---:|
| 2009-07-22 日全食 | 2009-07-22T02:35:18.100Z | 2009-07-22T02:35:17.551Z | -0.548 |
| 2023-10-14 日环食 | 2023-10-14T17:59:29.500Z | 2023-10-14T17:59:31.246Z | +1.746 |
| 2024-04-08 日全食 | 2024-04-08T18:17:18.300Z | 2024-04-08T18:17:23.627Z | +5.327 |
| 2025-03-14 月全食 | 2025-03-14T06:58:41Z | 2025-03-14T06:58:48.156Z | +7.156 |
| 2025-09-07 月全食 | 2025-09-07T18:11:43Z | 2025-09-07T18:11:47.703Z | +4.703 |

参考：Eclipse Predictions by Fred Espenak, NASA's GSFC。NASA 不对本程序背书。月食目录 TD 经对应 ΔT 换算为 UT；UT 与本程序 UTC≈UT1 约定也不是严格相同。原始出处和换算备注见 `tests/nasa-reference.json`、`docs/SOURCES.md`；完整模型限制见 `docs/PRECISION.md`。

## 6. 复现与打包

```bash
node tools/build.cjs
node tests/test.cjs
node tests/v2-test.cjs
python tests/server-test.py
xvfb-run -a env CHROMIUM=/usr/bin/chromium python tests/v2-browser-test.py
python tools/package.py
```

最后一项只用于开发交付，需要 Python 标准库和 Node。打包前重新构建并比对 SHA，拒绝与浏览器已测 HTML 不一致的版本；报告失败也不会输出正式 ZIP。打包后检查 ZIP CRC 和包内每个文件的 SHA256。`BUILD_MANIFEST.json` 记录交付文件，ZIP 外的同名 SHA256 文本可用于核对下载。普通使用只需打开 HTML。
