本地打开、后续更新与使用边界

完整解压后打开根目录 index.html。无需安装依赖，也无需启动后端。通过 Git 克隆的副本可双击 更新.cmd，或执行 git pull --ff-only，再重新打开首页；未提交的本地修改请先自行保存。

每个项目只保留一份当前代码，历史修改由 Git 管理。原项目中的版本标记属于来源信息，不代表首页提供多版本。线上与本地地址的学习记录不会自动互通；换地址、移动文件、清理浏览器前请备份。

化学与物理实验是屏幕中的教学模型，不要照着进行危险实物实验；人体和咖啡因动画不是医疗预测；武术为程序化教学编排，不是名家动作捕捉或医疗评估。地理图层是标明日期的精选资料，并非完整名录。项目内的数据出处、使用边界与许可说明继续保留。
